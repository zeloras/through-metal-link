# 実験 002: 3 mm鋼板を通しての最初のワット (計画中)

> [English (primary)](../../../../experiments/002-watts-3mm-steel/README.md) · [Русский](../../../ru/experiments/002-watts-3mm-steel/README.md) · [Deutsch](../../../de/experiments/002-watts-3mm-steel/README.md) · [Português](../../../pt/experiments/002-watts-3mm-steel/README.md) · [中文](../../../zh/experiments/002-watts-3mm-steel/README.md) · 日本語

- **ステージ:** 2 (既知の負荷に共振を発見した [001](../001-sweep-map-3mm-steel/README.md) の電力)。
- **目標:** ハーフブリッジドライバーとマッチングトランスフォーマーを使用して、3 mm鋼板を通して実際のDC電力を測定する。
- **仮説:** 同じバッチのランジュバン・トランスデューサー・ペア、グリース+クランプ（またはエポキシ）接触、および調整されたマッチングトランスフォーマーを使用すると、ステージ1のピークで≥0.5 Wの抵抗負荷が達成可能である。 (文献のマルチワット/キロワットの数字は、異なるトランスデューサーとボンディングを使用したため、天井として扱うべきであり、通過するための基準ではない。)
- **前提条件:**
  - 実験 001 を閉じる（再現可能なピーク、周波数を記録）。
  - RX チェーンに TVS を装着する ([docs/02-safety.md](../../docs/02-safety.md))。
  - ドライバーのブリングアップシーケンスに従う ([hardware/driver/README.md](../../../../hardware/driver/README.md))。
- **設定 (最小):**
  - TX: Pi → AD9833 平方 → デッドタイム シェイパー → IR2110 ハーフブリッジ → マッチング トランスフォーマー → プレートにクランプされたランジュバン ([sch1](../../../../hardware/schematics/sch1-driver-halfbridge.png))。
  - ウォール: 3 mm 鋼板、接触方法を記録する (グリース+クランプ / エポキシ / その他)。
  - RX: ランジュバン → ショットキー ブリッジ →既知の R_load (電力抵抗) および/または LED; ブリッジ後の V_dc と I_dc を測定 ([sch2](../../../../hardware/schematics/sch2-receiver-stage1.png) トポロジー、負荷を ADC のみではなく使用)。
- **手順 (アウトライン):**
  1. 電気的ブリングアップを 0.2 A PSU リミットで行うが、音響電力を主張しない。
  2. TX/RX をクランプし、駆動周波数を実験 001 のピークに設定する。
  3. 現在制限をゆっくり上げる; PSU の V/I、MOSFET/トランスフォーマーの温度、負荷の V_dc と I_dc をログする。
  4. P_load = V_dc · I_dc。オプション: LED デモ写真を 1 回、P_load がわかったら撮る。
  5. 冷却後、再度実行する。ピーク周波数は温度に応じて漂移する可能性があるため、電力が落ちる場合はミニスイープで再確認する。
- **成功基準:**
  1. 記録された周波数と接触方法で、3 mm 鋼板を通して P_load ≥ 0.5 W。
  2. クランプ/クーラントが同じであれば、2 つの実行で P_load が約 20% 以内で一致する (メトロロジー グレードではなく、オーダー オブ マグニチュードの安定性)。
  3. LED (またはその他の負荷) の写真 + このファイルからリンクされた CSV/ログ `data/`。
- **失敗はデータです:** P_load が ≪ 0.5 W の場合、ペア Δf (001 から)、接触方法、トランスフォーマーのターン数、および波形をログする。次の ADR の入力として使用し、シミュレーターを編集する理由ではありません。
