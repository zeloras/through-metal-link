# ハイブリッドチャネル：バリア → 物理 → 数値

> [English (primary)](../../../docs/04-hybrid-channels.md) · [Русский](../../ru/docs/04-hybrid-channels.md) · [Deutsch](../../de/docs/04-hybrid-channels.md) · [Português](../../pt/docs/04-hybrid-channels.md) · [Español](../../es/docs/04-hybrid-channels.md) · [Français](../../fr/docs/04-hybrid-channels.md) · [Italiano](../../it/docs/04-hybrid-channels.md) · [Polski](../../pl/docs/04-hybrid-channels.md) · [Türkçe](../../tr/docs/04-hybrid-channels.md) · [Українська](../../uk/docs/04-hybrid-channels.md) · [Tiếng Việt](../../vi/docs/04-hybrid-channels.md) · [中文](../../zh/docs/04-hybrid-channels.md) · 日本語 · [한국어](../../ko/docs/04-hybrid-channels.md) · [हिन्दी](../../hi/docs/04-hybrid-channels.md)

原理（「透過パラドックス」の帰結）：波がバリアを透過するのは、それと弱く相互作用する程度にちょうど等しい——だからこそ普遍なチャネルは存在しない。プラットフォームは単一のチャネルを追い求めない；各バリアに対して、そのバリアが透過し、受信器が共鳴的に「貪欲に」受け取る物理を選ぶ。

## チャネル選択テーブル

| バリア | 実用チャネル | 期待値（オーダー） | 備考 |
|---|---|---|---|
| 鋼/アルミ 1–60 mm、接触可能 | 圧電音響（我々の主力） | ワット；kbit/s（MHzモードで最大Mbit/s） | 音響接触が必要（グリースカップラント/エポキシ） |
| 金属：汚れ、塗装、高温、接触不可望 | EMAT（磁気 → 壁内の音） | mW；kbit/s；ギャップ最大~3 mm | 導電性壁のみ；電力ではなくデータ |
| 圧電素子が全く使えない強磁性壁 | 磁歪（コイルが鋼自体を駆動） | クローム；bit/s–kbit/s | 実験的ブランチ、テストは安価 |
| 真空を挟む二重壁（サーモス、クライオスタット、デュワー） | LF磁気（数十–数百Hz） | µW–mW；bit/s | 表皮効果：鋼ではδ≈0.6 mm @1 kHz — 周波数を下げる |
| 非金属：ガラス、プラスチック、セラミック | 圧電音響（金属より容易） | ワット；kbit/s | + 単純なRFも通ることが多い — まずそれを確認 |
| ゴム/フォーム層を含む壁、複合材 | 正直に言えば：ほぼ袋小路 | — | 吸収体がすべてを食う；回避策はコーティングのないスポット |
| 壁の裏に液体（満タンク） | 圧電音響、劣化 | 電力 − 数dB；リング短縮 | 液体負荷が共振をシフト/減衰させる — 満タンク状態で再スイープ；キャビテーション以下に保つため連続強度≲1 W/cm²を維持（[理論](00-theory.md#壁および壁の向こう側の媒体への影響)） |
| 音響経路上の気泡液体 | アーキテクチャ的回避策 | — | 受信器を壁に取り付け、液体を経路から外す |

## ハイブリッドノードアーキテクチャ

- 電力層：共振時の圧電ペア（ステージ1–4）。
- 非接触データ層：着脱可能な「スキャナガン」としてのEMATヘッド（ステージ~6）。
- フォールバック層：真空サンドイッチ用LFコイル（必要な場合）。
- ディスカバリプロトコル（docs/03）は「周波数スイープ」から「物理スイープ」へ拡張：圧電をping → EMATをping → LFをping；ノードは自力で通過するチャネルを選び、認識したバリアを報告する。

## チャネル別応用例

1. **密閉バッテリパック（EV/蓄電）：** ポッティング筐体内のT/ガスセンサー；2–3 mmアルミを通す圧電ペアで電力+データ。市場は急拡大中、バッテリ筐体への貫通＝認証地獄。
2. **クライオスタット/デュワー：** 内部の温度ロガーが、真空ジャケット越しにLF磁気で1分に1回ビットパケットを送信。音響では根本的に届かない — ここでハイブリッドは代替不能。
3. **加圧下のパイプライン/オートクレーブ：** 高温塗装パイプに表面処理ゼロで押し当てるEMATスキャナ — 内部の受動共振ビーコンを読み取る。
4. **発酵タンク（ビール/ワイン、ステンレス鋼）：** タンク内部の密度/Tセンサー、単一の貫通孔なし — 衛生規格は穴の不在を歓迎する。
5. **海上コンテナ/金庫：** 「積荷は生きているか」 — 波形鋼板を通す圧電ペア、ハンドヘルドスキャナでポーリング。

## どの層でも解決できない限界
電力 — 接触圧電のみ（EMATとLF磁気はオーダーが違うほど弱い）。複合/ゴム裏張り壁はプラットフォームの対象外。LFチャネル速度はビット毎秒 — それはストリーミングではなくテレメトリ。
