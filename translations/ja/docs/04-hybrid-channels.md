# ハイブリッドチャンネル: バリアー → 物理 → 数値

> [English (primary)](../../../docs/04-hybrid-channels.md) · [Русский](../../ru/docs/04-hybrid-channels.md) · [Deutsch](../../de/docs/04-hybrid-channels.md) · [Português](../../pt/docs/04-hybrid-channels.md) · [Español](../../es/docs/04-hybrid-channels.md) · [Français](../../fr/docs/04-hybrid-channels.md) · [Italiano](../../it/docs/04-hybrid-channels.md) · [Polski](../../pl/docs/04-hybrid-channels.md) · [Türkçe](../../tr/docs/04-hybrid-channels.md) · [Українська](../../uk/docs/04-hybrid-channels.md) · [Tiếng Việt](../../vi/docs/04-hybrid-channels.md) · [中文](../../zh/docs/04-hybrid-channels.md) · 日本語 · [한국어](../../ko/docs/04-hybrid-channels.md) · [हिन्दी](../../hi/docs/04-hybrid-channels.md)

原理（「貫通パラドックス」の帰結）：波は、バリアーと弱く相互作用する程度にのみバリアーを通過することができる — これが、汎用チャンネルが存在しない理由である。プラットフォームは、単一のチャンネルを追求しない；各バリアーに対して、バリアーが透過性を持つ物理と、受信機が共鳴して「貪欲」になる物理を選択する。

## チャンネル選択テーブル

| バリアー | 動作チャンネル | 予想（桁数） | ノート |
|---|---|---|---|
| 鋼鉄/アルミニウム 1–60 mm、接触可能 |圧電音響（我々のプライマリ） | ワット；kbit/s（MHz モードでは Mbit/s まで） | 音響接触（グリース カップリング/エポキシ）が必要 |
| 金属：汚れ、塗装、熱、接触は望ましくない | EMAT（磁気 → 音響） | mW；kbit/s；ギャップは約 3 mm まで | 導電性の壁のみ；データ、電力なし |
| 圧電素子なしの強磁性壁 | 磁歪（コイルが鋼鉄自体を駆動） | クラム；bit/s–kbit/s | 実験ブランチ、安価にテスト可能 |
| 真空（熱絶縁、クライオスタット、デュワ）を持つ二重壁 | 低周波磁気（数十〜数百 Hz） | μW–mW；bit/s | 皮相効果：鋼鉄では δ≈0.6 mm @1 kHz — 周波数を下げる |
| 非金属：ガラス、プラスチック、セラミック | 圧電音響（金属よりも簡単） | ワット；kbit/s | + 平坦 RF はよく通過する — それを最初に確認する |
| ゴム/泡の層、複合材を持つ壁 | 本当に：ほぼ死角 | — | 吸収材がすべてを食べる；対策はコーティングのないスポット |
| 壁の後ろに液体（満タン） | 圧電音響、劣化 | 電力 − 数 dB；短い鳴動 | 液体負荷が共鳴をシフト/減衰する — 満杯の容器に対して再スイープ；連続強度 ≲1 W/cm² を維持して気泡を避ける ([理論](00-theory.md#effect-on-the-wall-and-the-media-behind-it)) |
| 音響パスに気泡のある液体 | 建築上の対策 | — | 受信機を壁に取り付け、液体をパスから除外する |

## ハイブリッドノードアーキテクチャ

- 電力層：共鳴の圧電ペア（ステージ 1–4）。
- 非接触データ層：EMAT ヘッドを取り外し可能な「スキャナーガン」として（ステージ ~6）。
- フォールバック層：真空サンドイッチ用の低周波コイル（タスクが要求する場合）。
- 発見プロトコル（docs/03）を「周波数をスイープする」から「物理をスイープする」に拡張：圧電 → EMAT → 低周波をピング；ノードは独自に通過するチャンネルを選択し、見えるバリアーを報告する。

## チャンネルごとの例示的な応用

1. **密封バッテリーパック（EV/ストレージ）：** ポットに入ったエンクロージャ内に T/ガス センサー；2–3 mm アルミニウムを通過する圧電ペアによる電力+データ。市場はブームであり、バッテリー エンクロージャへの貫通 = 認定地獄。
2. **クライオスタット/デュワ：** 内部に温度 ロガー；1 分ごとにビット パケットを低周波磁気を介して真空 ジャケットを通過して送信。基本的に音響の範囲外 — ここではハイブリッドが不可欠。
3. **パイプライン/オートクレーブの圧力下：** 熱い塗装されたパイプに押し付けられた EMAT スキャナー — 内部から受動的な共鳴ビーコンを読み取る。
4. **発酵タンク（ビール/ワイン、ステンレス鋼）：** タンク内に単一の貫通なしで密度/T センサー。衛生コードは穴の不存在を愛する。
5. **海上コンテナ/金庫：** 「貨物は生きているか」 — コルゲート鋼を通過する圧電ペア；携帯スキャナーでポーリング。

## どの層でも解決できない制限
電力 — 接触圧電のみ（EMAT および低周波磁気は桁数が弱い）。複合/ゴムライニングの壁はプラットフォームの外である。低周波チャンネルの速度はビット/秒 — それはテレメトリであり、ストリーミングではない。
