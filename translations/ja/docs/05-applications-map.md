# アプリケーションマップ: どのような技術スタックが必要であり、理由は何であるか

> [English (primary)](../../../docs/05-applications-map.md) · [Русский](../../ru/docs/05-applications-map.md) · [Deutsch](../../de/docs/05-applications-map.md) · [Português](../../pt/docs/05-applications-map.md) · [Español](../../es/docs/05-applications-map.md) · [Français](../../fr/docs/05-applications-map.md) · [Italiano](../../it/docs/05-applications-map.md) · [Polski](../../pl/docs/05-applications-map.md) · [Türkçe](../../tr/docs/05-applications-map.md) · [Українська](../../uk/docs/05-applications-map.md) · [Tiếng Việt](../../vi/docs/05-applications-map.md) · [中文](../../zh/docs/05-applications-map.md) · 日本語 · [한국어](../../ko/docs/05-applications-map.md) · [हिन्दी](../../hi/docs/05-applications-map.md)

プラットフォームスタック: 盲壁を貫通するアクティブな電力およびデータチャネル — 圧電アクースティクス / EMAT / 低周波磁気。以下: これが実世界で必要とされる場所、誰がすでにそこにいるか、そして私たちにとって残されたもの。

## 1. 封じられたバッテリーパック (EV、家庭/産業用エネルギー貯蔵)
- 苦痛: 熱暴走の早期検出 — ガス (CO₂、H₂、電解液蒸気) がパック内に現れるのは火災の数分から数時間前; センサーの穿孔は封じ込めと認定の喪失を意味する。
- 私たちのスタック: パック内にガス/温度ノードを設置し、2〜3 mmのアルミニウムを介した圧電ペアで電力とテレメトリを送信。Zeroホール。
- すでに存在する者: Liminal Insights — 外側からの音響 *診断* (分析方法に関する特許、チャネルに関するものではない)。誰もがパック内にノードを販売していない。
- ニッチの成熟度: 市場は爆発的に成長しており、棚は空である。プラットフォームにとって — ショーケースアプリケーション #1。

## 2. 研究機器: 真空チャンバー、クライオスタット、グローブボックス
- 苦痛: 真空チャンバーへの電気的フィードスルーは、数百ドル相当のフランジと漏れの源となる; クライオスタットでは、ケーブル = 熱漏れ。
- 私たちのスタック: チャンバー内にセンサーを設置し、鋼壁を介した音で電力とデータを送信; デュアーの真空サンドイッチの場合 — 低周波磁気 (ビット/秒はT-ロガーには十分)。
- すでに存在する者: 壁を貫通するワイヤレス技術を持つ者はいない; 研究所はフィードスルーフランジに頼っている。
- 成熟度: オープンソースの理想的な開始ニッチ — 研究所は正にオープンハードウェアの対象者 (TinyLevの道) である: 認定without買い、論文に引用される。

## 3. 食品生産: 発酵タンク、オートクレーブ (ビール、ワイン、乳製品)
- 苦痛: 衛生コードは穿孔を嫌う (CIP洗浄、デッドゾーン); タンク内に密度/T/圧力を常に知りたい。
- 私たちのスタック: 不動のペアまたは携帯スキャナーでポーリングするステンレスタンクの内壁にノードを設置。
- すでに存在する者: 普通のタップインセンサー; 壁を貫通するワイヤレスソリューションはない。
- 成熟度: 文字通りガレージテストの手が届く範囲内 (どのクラフトブルワリーも歩いて行ける距離にある実証場)。
- 物理的注意事項: 満タンの場合、壁に負荷がかかる — 満タンの容器に対して再スイープし、連続電力 ≲1 W/cm²; それ以上の場合、キャビテーションが生じる (CO₂の脱気、風味の変化、壁の長期的な侵食) — [理論](00-theory.md#effect-on-the-wall-and-the-media-behind-it)。

## 4. パイプライン、圧力容器、産業用NDT
- 苦痛: 休止または穿孔なしに内部の腐食/パラメータを監視する; 表面は熱く、塗装され、汚れている。
- 私たちのスタック: EMAT "スキャナーガン" — 表面の準備なしにパイプに押し付け、内部から受動的な共鳴ビーコンを読み取る。
- すでに存在する者: クランプオン型超音波流量計と厚さ計 (成熟した市場) 但是、内部のインタラクティブビーコンはない。
- 成熟度: 中間; EMATブランチ (ステージ ~6) が必要。

## 5. 石油・ガス / ダウンホールおよび原子力
- すでに存在する者: Metrol、Acoustic Data、Baker Hughes (ダウンホール、30年、サービスモデル); DOE/UNT/Westinghouse R&D (原子力キャニスター)。
- 誠実な評価: すでに占有されており、厳しく規制されている — 私たちはそこへ行かないが、その存在自体 = この物理が真剣なお金で売れることを証明する。READMEに参考として使用する。

## 6. 海上ロジスティクスおよび水中構造物
- 苦痛: 封じられたコンテナ内に "貨物は生きているか"; 船の船体の内側からのデータ。
- すでに存在する者: CSignum (水/隔壁を介した低周波EM) — ハイブリッド哲学における唯一の直接の隣人。
- 成熟度: 長期; 私たちにとって、現在は考え方の方向のみ。

## 優先順位 (何を何の順序で行うか)
1. **今:** プラットフォームステージ 1〜4 をショーケースシナリオ "研究室チャンバー / 封じ込めボックス" (ニッチ #2 — オープンソースに最も開かれている) に適用。
2. **次:** ニッチ #3 (醸造タンク) の実際のオブジェクトでのデモ — 安価、写真撮りやすい、実際のユーザー。
3. **中期:** バッテリーシナリオ (ニッチ #1) を出版のための旗艦ケースとして; ニッチ #4 用のEMATブランチ。

*パッシブビジョン (ミューオン放射線断層撮影) は、別のプロジェクトにスピンオフされた — ナレッジベースの muon-lab を参照してください。
