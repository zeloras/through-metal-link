# アプリケーションマップ：この技術スタックを必要とするのは誰か、そしてなぜか

> [English (primary)](../../../docs/05-applications-map.md) · [Русский](../../ru/docs/05-applications-map.md) · [Deutsch](../../de/docs/05-applications-map.md) · [Português](../../pt/docs/05-applications-map.md) · [Español](../../es/docs/05-applications-map.md) · [Français](../../fr/docs/05-applications-map.md) · [Italiano](../../it/docs/05-applications-map.md) · [Polski](../../pl/docs/05-applications-map.md) · [Türkçe](../../tr/docs/05-applications-map.md) · [Українська](../../uk/docs/05-applications-map.md) · [Tiếng Việt](../../vi/docs/05-applications-map.md) · [中文](../../zh/docs/05-applications-map.md) · 日本語 · [한국어](../../ko/docs/05-applications-map.md) · [हिन्दी](../../hi/docs/05-applications-map.md)

プラットフォームスタック：密閉壁を貫通するアクティブな電力・データチャネル — 圧電音響 / EMAT / 低周波磁気。以下に、現実世界でどこに必要とされ、誰がすでにそこにいて、何が私たちに残されているかを示す。

## 1. 密閉バッテリーパック（EV、家庭・産業用エネルギー貯蔵）
- 課題：熱暴走の早期検出 — ガス（CO₂、H₂、電解液蒸気）は発火の数分から数時間前にパック内部に現れる；エンクロージャーへのセンサー貫通 = 気密性と認証の喪失。
- 当方のスタック：パック内部のガス/温度ノード、2–3 mm のアルミニウムを貫通する圧電ペアで電力とテレメトリーを供給。穴なし。
- すでにいるプレイヤー：Liminal Insights — 外側からの音響*診断*（分析手法の特許であり、チャネルの特許ではない）。パック*内部*のノードを販売している者はいない。
- ニッチの成熟度：市場は爆発的に成長中、棚は空っぽ。プラットフォームにとって — ショーケースアプリケーション #1。

## 2. 実験室機器：真空チャンバー、クライオスタット、グローブボックス
- 課題：真空チャンバーへの電気フィードスルーはすべて数百ドルのフランジであり、リーク源でもある；クライオスタットではケーブル = 熱リーク。
- 当方のスタック：チャンバー内部のセンサー、鋼壁を通して音で電力/データを供給；デュワーの真空サンドイッチには — 低周波磁気（Tロガーには bit/s で十分）。
- すでにいるプレイヤー：壁貫通無線で参入している者はいない；実験室はフィードスルーフランジで生きている。
- 成熟度：オープンソースにとって理想的な出発ニッチ — 実験室はまさにオープンハードウェアの対象者（TinyLev の道）：認証なしで購入し、論文で引用してくれる。

## 3. 食品製造：発酵タンク、オートクレーブ（ビール、ワイン、乳製品）
- 課題：衛生規格は貫通を嫌う（CIP 洗浄、デッドゾーン）；タンク内の密度/温度/圧力を常に把握したい。
- 当方のスタック：ステンレスタンクの内壁にノードを配置、外部からハンドヘルドスキャナーまたは固定ペアでポーリング。
- すでにいるプレイヤー：通常のタップイン式センサー；壁貫通無線ソリューションなし。
- 成熟度：文字通りガレージテストの範囲内（クラフトブルワリーは歩いて行ける距離の実証場）。
- 物理的注意点：満タンのタンクは壁に負荷をかける — 満タンの容器に対して再スイープし、連続電力を ≲1 W/cm² に保つこと；それ以上では製品中にキャビテーション（CO₂ 脱ガス、オフフレーバー、長期的な壁の浸食）が発生 — [理論](00-theory.md#壁および壁の向こう側の媒体への影響)。

## 4. パイプライン、圧力容器、産業用 NDT
- 課題：停止や貫通なしに内部の腐食/パラメータを監視；表面は高温、塗装済み、汚れている。
- 当方のスタック：EMAT「スキャナーガン」 — 表面処理ゼロでパイプに押し当て、内部からパッシブ共振ビーコンを読み取る。
- すでにいるプレイヤー：クランプオン超音波流量計と厚さ計（成熟した市場）、ただし内部のインタラクティブビーコンはない。
- 成熟度：中域；EMAT ブランチが必要（ステージ ~6）。

## 5. 石油・ガス / 坑井、および原子力
- すでにいるプレイヤー：Metrol、Acoustic Data、Baker Hughes（坑井、30年、サービスモデル）；DOE/UNT/Westinghouse の R&D（原子力キャニスター）。
- 正直な評価：占有されており規制が厳しい — 我々はそこには行かないが、その存在自体 = この物理が真剣な金で売れる証拠。README の参考として使用。

## 6. 海上物流と水中構造物
- 課題：密閉コンテナ内の「貨物は生きているか」；船体の内側からのデータ。
- すでにいるプレイヤー：CSignum（水中/隔壁を通す低周波 EM） — ハイブリッド哲学における唯一の直接の隣人。
- 成熟度：長距離；当面は思考の方向性としてのみ。

## 優先順位（何を、どの順序でやるか）
1. **今：** ショーケースシナリオ「実験室チャンバー / 溶接密閉ボックス」でプラットフォームステージ 1–4（ニッチ #2 — オープンソースに最も開かれている）。
2. **次：** ニッチ #3 の実物（ブルワリータンク）でのデモ — 安価、映える、実ユーザー。
3. **中域：** バッテリーシナリオ（ニッチ #1）を出版用の旗艦ケースに；ニッチ #4 の EMAT ブランチ。

*パッシブビジョン（ミューセンシング）は別プロジェクトとしてスピンオフされた — ナレッジベースの muon-lab を参照。*
