固体金属壁を通じた超音波電力/データ通信用オープンガレージプラットフォームの、初の日付付き公開スナップショット。

## このタグの位置づけ
- タグ付けコミット時点のドキュメント + ソフトウェア + BOM + 実験プロトコル
- シミュレータ / モックパイプラインのみ — **ラボ計測データは一切含まない**
- 引用 / 後日の Zenodo 登録に適する — **「ベンチで動いた」リリースではない**

## 含まれるもの
- Stage-0 README の正直な記述（シミュレータ ≠ ラボデータ）
- QUICKSTART + stage-1 BOM
- スイープマップ `--mock` およびチャネルシミュレータ
- 実験テンプレート 001 / 002
- ビルド Q&A: [Discussion #35](https://github.com/zeloras/through-metal-link/discussions/35)
- ハードウェアバウンティ: [Issue #5](https://github.com/zeloras/through-metal-link/issues/5)

## 含まれないもの
- 実験 001 / 002 の計測 CSV / 写真 / 動画
- 鋼壁を通じた保証ワット数
