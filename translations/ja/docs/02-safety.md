# Safety

> [English (primary)](../../../docs/02-safety.md) · [Русский](../../ru/docs/02-safety.md) · [Deutsch](../../de/docs/02-safety.md) · [Português](../../pt/docs/02-safety.md) · [中文](../../zh/docs/02-safety.md) · 日本語

1. **パイエゾの高電圧。** 共振時、ステージ2のドライバーがオンラインになると、トランスデューサーの端子に10から100ボルトの電圧がかかる。TVS/ゼネルダイオードは、最初のパワードランの前に受信側に接続する。動作中は端子に触れない。
2. **メイン電源。** 超音波クリーナードライバーはメイン電源とガルバニックに結合されている。ラボパワーサプライまたはアイソレーショントランスフォーマーを介してのみ作業する。このプロジェクトのハーフブリッジは、メイン電源接続されたクリーナーボードではなく、電流制限付きのベンチPSUから動作するように設計されている。
3. **耳。** 人間は40 kHzを聞くことができないが、サブハーモニックと動物は聞くことができる。非自明な電力の場合、金属に押し付けられたエミッターで作業し、空気中に放射しない。強力な空気中超音波 — エンクロージャーなしにオンにしない。
4. **加熱。** ロードされていないランジュバン・トランスデューサー（何にも押し付けられていない）は、満充電で数分以内に過熱する。**デフォルトルール：** プレート（または犠牲ブロック）にクランプする前に電力を上げる。ハーフブリッジの電気的ブリングアップ（PSUは約0.2 Aに制限され、秒単位ではなく分単位、スイッチノードにスコープ）のみは、[hardware/driver/](../../../hardware/driver/README.md) で説明されているように、意図的な例外である — まだ空気中のパワーランではない。
5. **破片。**圧電セラミックは脆い；過緊したランジュバン・ボルトまたは衝撃 = 破片。機械作業中は安全メガネ。
6. **ステージ1 vs ステージ2。** ステージ1のスイープはTXを弱いAD9833の正弦波（約0.6 Vpp）で駆動し、電気的に優しい；上記のほとんどの危険は、IR2110ハーフブリッジとマッチングトランスフォーマーがオンラインになると現実になる。
