# レシーバ発見およびオートチューニングプロトコル（スケッチ；実装はステージ2〜4）

> [English (primary)](../../../docs/03-discovery-protocol.md) · [Русский](../../ru/docs/03-discovery-protocol.md) · [Deutsch](../../de/docs/03-discovery-protocol.md) · [Português](../../pt/docs/03-discovery-protocol.md) · [Español](../../es/docs/03-discovery-protocol.md) · [Français](../../fr/docs/03-discovery-protocol.md) · [Italiano](../../it/docs/03-discovery-protocol.md) · [Polski](../../pl/docs/03-discovery-protocol.md) · [Türkçe](../../tr/docs/03-discovery-protocol.md) · [Українська](../../uk/docs/03-discovery-protocol.md) · [Tiếng Việt](../../vi/docs/03-discovery-protocol.md) · [中文](../../zh/docs/03-discovery-protocol.md) · 日本語 · [한국어](../../ko/docs/03-discovery-protocol.md) · [हिन्दी](../../hi/docs/03-discovery-protocol.md)

目標：デバイスが自律的に壁の向こうにレシーバがあるかどうかを判断し、周波数と電力を自ら選択し、誰かが「レシーバの溶接を忘れた」せいで壁を無駄に焼くことがないようにする。

ロールモデルはQi充電器である：まさにこの問題（コイル上にスマホがあるか？）を、まさにこの手順で解決している。我々の音響版アナログ：

## フェーズ0 — アナログピング（レシーバは完全放電していてもよい）
TXはバンド全体にわたり低電力スイープを実行し、**自身の電流と位相**を測定する（シャント＋ピーク検出器 → ADS1115）。壁の向こうにある共振レシーバは、壁を通してTXに結合される負荷である：内部がすべて無電力であっても、その存在はTXインピーダンス曲線上の特徴的なディップ/バンプとして現れる。金属探知機やQiのアナログピングと同じ原理。
- シグネチャあり → フェーズ1へ。シグネチャなし → 「レシーバ未検出」とし、スタンバイピング（N秒に1回）を継続し、電力を上げない。
- ボーナス：「空の」壁のインピーダンス曲線は設置時にリファレンスとして記録される — これにより「レシーバなし」と「レシーバが外れた／ズレた」を区別できる。

## フェーズ1 — デジタルハンドシェイク
TXは候補周波数（フェーズ0のピーク）に留まり、電力を供給する。RXのハーベスタがスーパーキャパシタを充電し、MCUが起動して**負荷変調**で応答する：MOSFETがコード（ID＋プロトコルバージョン）に従って圧電素子を周期的にショートする。TXはこれを自身の電流の変調として観測する。内部に送信機は一切不要 — これはRFID方式であり、放棄されたDOE/RPI出願US20100027379（フリーな先行技術）と同じものである。

## フェーズ2 — 周波数サーボチューニング（摂動＆観測）
RXはバス電圧を報告できる（負荷変調によるテレメトリ）。TXは±Δfずつステップし、受電力の最大値を保持する — 古典的なMPPTループである。これにより温度による共振ドリフトを補正する（このニッチの最大の落とし穴：〜6%のシフト = 〜10×の効率低下）。

## フェーズ3 — 電力ネゴシエーションとウォッチドッグ
RXがレベルを要求し（稼働中／充電中／もっとくれ）、TXは要求された値で電力を制限する。Mサイクルの応答欠落 → TXは低電力でフェーズ0にフォールバックする。

## これに必要なハードウェア（BOM項目12、回路図 — hardware/schematics/sch4）
- TX：0.1 Ωシャント＋整流器/ピーク検出器をADS1115の第2チャネル（電流）に接続、オプションで位相比較器。
- RX：2N7002＋〜100 Ωを整流器の**DC側**（LTC3588モジュールのVINピン）に接続 ＋ GPIO — ブリッジ後段で負荷を切り替え、TXはそれを自身の電流の変調として観測する。AC圧電素子をまたぐ単一のMOSFETでは動作しない（ボディダイオードが半波をショートし、ゲートがフローティングノードに基準を持たない）；圧電素子をまたぐ方式は、バックツーバック直列のMOSFETペアでのみ機能する。

## 制限事項
アナログピングは壁厚および接触損失の増大に伴って弱くなる（シグネチャがノイズに埋もれる） — 検出しきい値は専用の実験（experiments/）で測定しなければならない。厚い壁に対するフォールバック：RXは十分に電荷を蓄えた後、自身のビーコンで周期的に「ノック」する。
