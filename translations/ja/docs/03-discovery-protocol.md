# 受信機の検出と自動チューニングプロトコル（スケッチ；実装はステージ2–4）

> [English (primary)](../../../docs/03-discovery-protocol.md) · [Русский](../../ru/docs/03-discovery-protocol.md) · [Deutsch](../../de/docs/03-discovery-protocol.md) · [Português](../../pt/docs/03-discovery-protocol.md) · [Español](../../es/docs/03-discovery-protocol.md) · [Français](../../fr/docs/03-discovery-protocol.md) · [Italiano](../../it/docs/03-discovery-protocol.md) · [Polski](../../pl/docs/03-discovery-protocol.md) · [Türkçe](../../tr/docs/03-discovery-protocol.md) · [Українська](../../uk/docs/03-discovery-protocol.md) · [Tiếng Việt](../../vi/docs/03-discovery-protocol.md) · [中文](../../zh/docs/03-discovery-protocol.md) · 日本語 · [한국어](../../ko/docs/03-discovery-protocol.md) · [हिन्दी](../../hi/docs/03-discovery-protocol.md)

目標：デバイスが壁の向こうに受信機があるかどうかを自動的に判断し、周波数と電力を自動的に選択し、受信機が「溶接されていない」という理由で壁を無駄に加熱しないようにする。

参考モデルはQi充電器：同じ問題（コイル上に電話があるかどうか）を同じシーケンスで解決する。私たちの音響アナログ：

## フェーズ0 — アナログピン（受信機は完全に放電されている場合）
TXはバンド全体で低電力のスイープを実行し、**自身の電流と位相**（シャント + ピーク検出 → ADS1115）を測定する。壁の向こうに共鳴受信機がある場合、それはTXに接続された負荷として現れ、特徴的な低下/上昇をTXのインピーダンス曲線上に示す。メタル探知機やQiのアナログピンの原理と同じ。
- 署名が存在する場合 → フェーズ1。署名が存在しない場合 → 「受信機が見つかりませんでした」というメッセージを表示し、スタンバイピン（毎秒N回）を維持し、電力を上げない。
- ボーナス：「空」の壁のインピーダンス曲線は、設置時に参照として記録されるため、「受信機なし」と「受信機が外れた/配置がずれている」を区別できる。

## フェーズ1 — デジタルハンドシェイク
TXは候補周波数（フェーズ0のピーク）に停車し、電力を供給する。RXハーベスターはスーパーキャパシタを充電し、MCUは起動し、**負荷変調**で応答する：MOSFETは周期的にピエゾをショートし、コード（ID + プロトコルバージョン）に従う。TXはこれを自身の電流の変調として見る。内部に送信機は必要ない — これはRFIDスキームであり、放棄されたDOE/RPIアプリケーションUS20100027379（無料の先行技術）と同じ。

## フェーズ2 — 周波数サーボチューニング（攪乱と観察）
RXはバス電圧（負荷変調を介したテレメトリ）を報告できる。TXは±Δfをステップし、受信電力の最大値を保持する — クラシックなMPPTループ。これにより、温度による共鳴ドリフト（ニッチの主な問題：約6%のシフト = 約10倍の効率低下）が解消される。

## フェーズ3 — 電力交渉とウォッチドッグ
RXはレベル（生存/充電/もっと与えてください）を要求し、TXは要求された電力で電力を制限する。Mサイクル間で応答が欠けている場合、TXはフェーズ0に戻り、低電力で動作する。

## 必要なハードウェア（BOMアイテム12、回路図 — hardware/schematics/sch4）
- TX：0.1 Ωのシャント + 二次ADS1115チャンネル（電流）上的整流器/ピーク検出、オプションで位相比較器。
- RX：2N7002 + ~100 Ωの**DC側**の整流器（LTC3588モジュールのVINピン）+ GPIO — 負荷はブリッジの後で切り替わり、TXはこれを自身の電流の変調として見る。単一のMOSFETがACピエゾ全体に接続されている場合、動作しない（ボディダイオードが半波をショートし、ゲートに浮動ノード上の参照がない）；ピエゾ全体に接続されたバリアントは、バックツーバックのシリアルMOSFETのペアでのみ動作する。

## 制限
アナログピンは壁の厚さと接触損失の増加に弱くなる（署名はノイズに溺れる） — 検出閾値は専用の実験（experiments/）で測定する必要がある。厚い壁のためのフォールバック：RXは、充電した電力を蓄積した後、周期的に「ノック」信号を送信する。
