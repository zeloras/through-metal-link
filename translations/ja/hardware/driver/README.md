# ドライバ（ステージ2）：IR2110ハーフブリッジ

**回路図:** [../schematics/sch1-driver-halfbridge.png](../schematics/sch1-driver-halfbridge.png)（[../schematics/render_schematics.py](../../../../hardware/schematics/render_schematics.py) で生成）

信号チェーン：Pi（SPI）→ AD9833 **矩形波モード**（OPBITENビット：MSBが出力にルーティングされ、レールtoレールの振幅 — コンパレータは別途不要）→ **74HC14 + RC + 1N4148** シェーパ（相補的なHIN/LIN、約1 µsのデッドタイム付き）→ IR2110 → 2×IRF540（ハーフブリッジ）→ 1 µF DCブロッキングキャップ → マッチングトランス（フェライト、約1:3..1:5、ベンチで同調）→ ランジュバン振動子TX。

AD9833のサイン出力（約0.6 Vpp）はIR2110のロジックには不適切 — 何らかの理由でDDSからサイン波がどうしても必要な場合は、間にコンパレータを入れてください（例：LM393、BOMには含まれません）。

パワーステージ電源：12–24 Vのベンチ用PSU、電流制限付き（**0.2 Aから開始**）。

注意：ステージ1のスイープは弱いDDSサイン（約0.6 Vpp、`sweep_map.py`を参照）で圧電素子を直接駆動します — **このドライバはステージ2（ワット級）でのみチェーンに組み込まれます**。ステージ1のDDSのみの接続で0.5 W以上を期待しないでください。

注意事項：
- ランジュバン振動子は容量性負荷です（通常数nF）。直列インダクタまたはマッチングトランスが必須です。これがないとMOSFETが無効電流を消費して過熱破損します。
- **マッチングトランス（よくある故障ポイント）。** 小さなフェライトトロイダル（例：FT50-43 / 類似品）から始め、1次側は数ターン、2次側はその3–5倍、1次側に直列DCブロック1 µFフィルムキャップ。TXを**プレートにクランプ**し、RXを負荷接続した状態で、*ステージ1の共振周波数*でPSU電流が最小になるよう同調します。ターン比と漏れインダクタンスは経験的に決める — 回路図で`*`と記されているのには理由があります。最終的なターン数は実験ログに記録してください。
- **デッドタイム**：IR2110単体では生成しません。ディスクリート部品による方法 — 74HC14の入力にRC+1N4148（立ち上がりエッジのみ遅延、約1 µs；40 kHzで25 µs周期なら5%未満のロス）。簡単な方法 — EGS002モジュールを使えば、すべて内蔵されています。
- **3.3 Vロジック**：IR2110のVDDはAD9833や74HC14と同じ3.3 Vから供給 — VDD=5 VではVIHスレッショルドが約3.1 Vとなり、3.3 V矩形波はギリギリ通過します（データシートではVDDは3.3 Vまで許容）。
- **デカップリングは必須**：VDDとVCCに100 nF（VCC — さらに47 µF）、電源レールにはハーフブリッジのレグ直近に470–1000 µF + 100 nFセラミック — これがないと、ブレッドボードのジャンパ線上のハーフブリッジが自身のスイッチングスパイクを拾います。電力ループの配線は短く；スイッチノードのリンギングがひどい場合は、電流を上げる前にブレッドボードから銅張りのデッドバグ / プロトボードのグラウンドプレーンに移行してください。
- **初回電源投入手順**（[docs/02-safety.md](../../docs/02-safety.md) に準拠）：
  1. まだ2次側にランジュバンは接続しない。PSU = 12 V、電流制限0.2 A。スコープでゲートドライブ（HIN/LIN）とスイッチノードを確認 — デッドタイムと貫通短路の有無を確認。
  2. マッチングトランス + TXランジュバンを**鋼板にクランプ**（または厚い犠牲金属ブロック）。まだ0.2 A制限のまま。ステージ1のピーク周波数で、電流とRX電圧が確認できる程度の短時間だけ通電。
  3. MOSFETとトランスの温度を監視しながら、電流制限を徐々に上げる。クランプされていないランジュバンに電力を加えたまま放置しない — 空気中での全功率運転はセラミックが割れ、ドライバが死ぬ原因です。
