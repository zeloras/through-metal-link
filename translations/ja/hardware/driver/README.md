# ドライバー (ステージ 2): IR2110 ハーフブリッジ

> [English (primary)](../../../../hardware/driver/README.md) · [Русский](../../../ru/hardware/driver/README.md) · [Deutsch](../../../de/hardware/driver/README.md) · [Português](../../../pt/hardware/driver/README.md) · [中文](../../../zh/hardware/driver/README.md) · 日本語

**回路図:** [../schematics/sch1-driver-halfbridge.png](../schematics/sch1-driver-halfbridge.png) (生成元: [../schematics/render_schematics.py](../../../../hardware/schematics/render_schematics.py))

連携: Pi (SPI) → AD9833 **正方形波モード** (OPBITEN ビット: MSB が出力にルーティングされ、レールツーレールのスイング — 比較器は必要ありません) → **74HC14 + RC + 1N4148** シェイパー (補完的な HIN/LIN で約 1 µs のデッドタイム) → IR2110 → 2×IRF540 (ハーフブリッジ) → 1 µF DC ブロッキング キャップ → マッチング トランス (フェライト、約 1:3..1:5、ベンチで調整) → ランジュバン トランスデューサー TX。

AD9833 の正弦出力 (~0.6 Vpp) は、IR2110 のロジックには適していません。如果何らかの理由で DDS から正弦出力を必要とする場合、それらの間に比較器 (例: LM393、BOM にありません) を配置します。

パワーステージ サプライ: 12–24 V ベンチ PSU で電流制限 (**0.2 A から開始**).

注意: ステージ 1 のスイープは、直接弱い DDS 正弦 (~0.6 Vpp、`sweep_map.py` 参照) でピエゾを駆動します — **このドライバーはステージ 2 (ワット) でしか連携しません**。ステージ 1 の DDS のみの接続では 0.5 W 以上を期待しないでください。

注意事項:
- ランジュバン トランスデューサーは、容量負荷 (通常は数 nF) です。シリーズインダクタまたはマッチング トランスは必須です。そうでない場合、MOSFET は反応電流を消費し、熱を発生します。
- **マッチング トランス (通常の故障点)。** 小さなフェライト トロイド (例: FT50-43 / 類似品) から始め、プライマリを数回転、セカンダリを約 3–5 倍にします。プライマリに 1 µF のフィルムを直列に接続します。ステージ 1 の共振で TX を **板に固定** し、RX を負荷し、最小の PSU 電流を調整します。ターン比と漏れは経験則に基づいています — 回路図ではそれらを `*` で示しています。最終的なターン数を実験ログに記録します。
- **デッドタイム**: IR2110 では独自に生成されません。ディスクリート パーツ オプション — 74HC14 入力の RC+1N4148 (立ち上りエッジのみを遅延、約 1 µs; 40 kHz で 25 µs の周期の場合、<5% の損失)。簡単なオプション — EGS002 モジュール、すべてがビルトインです。
- **3.3 V ロジック**: IR2110 の VDD を、AD9833 と 74HC14 と同じ 3.3 V で駆動します。VDD=5 V の場合、VIH 阈値は約 3.1 V であり、3.3 V の正方形波はほとんど通過しません (データシートでは VDD を 3.3 V まで下げることを許可しています)。
- **デカップリングは必須**: VDD と VCC (VCC — さらに 47 µF)、およびパワーレール 470–1000 µF + 100 nF セラミック (ハーフブリッジの脚のすぐ近く) に 100 nF を配置します。そうでない場合、パンブレッドボードのジャンパー上のハーフブリッジは、自身のスイッチング スパイクを拾います。パワーロープ ワイヤを短く保ちます。如果スイッチ ノードがひどくリングする場合、カレントを上げる前にパンブレッドボードから、コッパークラッド デッドバグ / プロトボード グラウンド ポアに移動します。
- **最初の電源オンシーケンス** ([docs/02-safety.md](../../docs/02-safety.md) と一致):
  1. まだランジュバンはセカンダリにありません。PSU = 12 V、電流制限 0.2 A。スコープ ゲート ドライブ (HIN/LIN) とスイッチ ノード — デッドタイムとスルー シュートのないことを確認します。
  2. マッチング トランス + TX ランジュバン **鋼板に固定** (または厚い犠牲金属 ブロック) を装着します。まだ 0.2 A 制限です。ステージ 1 のピーク周波数でのみ、電流と RX 電圧を確認するのに十分な時間をかけてください。
  3. 電流制限を逐渐に上げながら、MOSFET とトランスフォーマーの温度を監視します。ランジュバンが固定されていない場合、電源を入れないでください — フリーエア フルパワーランは、セラミックが破損し、ドライバーが故障する原因となります。
