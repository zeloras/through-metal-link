Перший датований публічний знімок відкритої гаражної платформи для ультразвукової передачі енергії/даних крізь суцільні металеві стінки.

## Що являє собою цей тег
- Документація + програмне забезпечення + BOM + протоколи експериментів станом на помічений коміт
- Лише симулятор / макетний конвеєр — **жодних лабораторних вимірювань не заявлено**
- Придатний для цитування / подальшого Zenodo; **не** є релізом типу «працює на лабораторному стенді»

## Включено
- Чесність README Stage-0 (симулятор ≠ лабораторні дані)
- QUICKSTART + BOM для stage-1
- Sweep-map `--mock` та симулятор каналу
- Шаблони експериментів 001 / 002
- Q&A зі збірки: [Discussion #35](https://github.com/zeloras/through-metal-link/discussions/35)
- Баунті за апаратну частину: [Issue #5](https://github.com/zeloras/through-metal-link/issues/5)

## Не включено
- Виміряні CSV / фото / відео для експериментів 001 / 002
- Гарантовані вати крізь сталь
