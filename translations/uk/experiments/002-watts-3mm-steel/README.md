# Експеримент 002: Перші вати крізь 3 мм сталі (ЗАПЛАНОВАНО)

> [English (primary)](../../../../experiments/002-watts-3mm-steel/README.md) · [Русский](../../../ru/experiments/002-watts-3mm-steel/README.md) · [Deutsch](../../../de/experiments/002-watts-3mm-steel/README.md) · [Português](../../../pt/experiments/002-watts-3mm-steel/README.md) · [Español](../../../es/experiments/002-watts-3mm-steel/README.md) · [Français](../../../fr/experiments/002-watts-3mm-steel/README.md) · [Italiano](../../../it/experiments/002-watts-3mm-steel/README.md) · [Polski](../../../pl/experiments/002-watts-3mm-steel/README.md) · [Türkçe](../../../tr/experiments/002-watts-3mm-steel/README.md) · Українська · [Tiếng Việt](../../../vi/experiments/002-watts-3mm-steel/README.md) · [中文](../../../zh/experiments/002-watts-3mm-steel/README.md) · [日本語](../../../ja/experiments/002-watts-3mm-steel/README.md) · [한국어](../../../ko/experiments/002-watts-3mm-steel/README.md) · [हिन्दी](../../../hi/experiments/002-watts-3mm-steel/README.md)

- **Етап:** 2 (потужність у відому нагрузку на резонансі, знайденому в [001](../001-sweep-map-3mm-steel/README.md)).
- **Мета:** виміряти реальну потужність постійного струму, передану крізь 3 мм сталі за допомогою півмостового драйвера та узгоджувального трансформатора.
- **Гіпотеза:** з парою Ланжевенів з однієї партії, контактом мастило+затиск (або епоксид) та налаштованим узгоджувальним трансформатором, ≥0,5 Вт у резистивне навантаження на піку етапу 1 є досяжним. (Багатоватні/кВт-ні показники з літератури використовували інші перетворювачі та склеювання — сприймайте їх як стелю, а не як прохідний бар'єр.)
- **Передумови:**
  - Експеримент 001 закрито (відтворюваний пік, частоту зафіксовано).
  - TVS встановлено в ланцюгу RX до подачі живлення на драйвер ([docs/02-safety.md](../../docs/02-safety.md)).
  - Дотримано послідовність увімкнення драйвера ([hardware/driver/README.md](../../../../hardware/driver/README.md)).
- **Налаштування (мінімум):**
  - TX: Pi → AD9833 square → формувач мертвого часу → півміст IR2110 → узгоджувальний трансформатор → Ланжевен, затиснутий до пластини ([sch1](../../../../hardware/schematics/sch1-driver-halfbridge.png)).
  - Стіна: 3 мм сталь, метод контакту зафіксовано (мастило+затиск / епоксид / інше).
  - RX: Ланжевен → міст Шотткі → відомий R_load (потужний резистор) та/або світлодіод; виміряти V_dc та I_dc після моста ([sch2](../../../../hardware/schematics/sch2-receiver-stage1.png) топологія, навантаження замість лише АЦП).
- **Процедура (коротко):**
  1. Електричне увімкнення при обмеженні БЖ 0,2 А без заявлення акустичної потужності.
  2. Затиснути TX/RX, встановити частоту драйвера на пік експерименту 001.
  3. Підвищувати обмеження струму поступово; записувати V/I БЖ, температуру MOSFET/трансформатора, V_dc та I_dc на навантаженні.
  4. P_load = V_dc · I_dc. Необов'язково: коротке демо-фото світлодіода, коли P_load відомо.
  5. Повторити один раз після охолодження; пікова частота може дрейтувати з температурою — перевірити міні-свепом, якщо потужність падає.
- **Критерії успіху:**
  1. P_load ≥ 0,5 Вт крізь 3 мм сталі при задокументованій частоті та методі контакту.
  2. Два прогони узгоджуються за P_load у межах ~20% за тих самих затиску/контакту (стабільність на рівні порядку величини, ще не метрологічного класу).
  3. Фото світлодіода (або іншого навантаження) + CSV/лог, посилання з цього файлу у `data/`.
- **Невдача — це дані:** якщо P_load залишається ≪ 0,5 Вт, зафіксуйте Δf пари (з 001), метод контакту, кількість витків трансформатора та осцилограми — це вхід для наступного ADR, а не причина мовчазно редагувати симулятор.
