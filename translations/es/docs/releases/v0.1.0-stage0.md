Primera snapshot pública fechada de la plataforma abierta de garaje para potencia/datos ultrasónicos a través de paredes de metal sólido.

## Qué es esta etiqueta
- Documentación + software + BOM + protocolos de experimentos tal como están en el commit etiquetado
- Solo pipeline de simulador / mock — **no se afirman mediciones de laboratorio**
- Adecuado para citación / futuro Zenodo; **no** es un release de “funciona en el banco”

## Incluido
- Honestidad del README Stage-0 (simulador ≠ datos de laboratorio)
- QUICKSTART + BOM de stage-1
- Sweep-map `--mock` y simulador de canal
- Plantillas de experimento 001 / 002
- Preguntas y respuestas de build: [Discussion #35](https://github.com/zeloras/through-metal-link/discussions/35)
- Recompensa de hardware: [Issue #5](https://github.com/zeloras/through-metal-link/issues/5)

## No incluido
- CSV medidos / fotos / video para exp 001 / 002
- Watts garantizados a través de acero
