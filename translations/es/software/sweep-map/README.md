Mapa de barrido de la respuesta en frecuencia del canal. Consulta la cabecera de sweep_map.py para el hardware, cableado y cómo ejecutarlo.

Entorno (las versiones recientes de Raspberry Pi OS requieren un venv):

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r ../requirements.txt spidev smbus2   # spidev/smbus2 — solo en la Pi
```

En la Pi: `raspi-config` → activa SPI e I2C.

Ejecución en seco sin hardware, en cualquier ordenador (basta con matplotlib):

```bash
python3 sweep_map.py --mock
```
