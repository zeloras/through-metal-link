## यह टैग क्या है
- टैग किए गए कमिट तक के डॉक्स + सॉफ़्टवेयर + BOM + प्रयोग प्रोटोकॉल
- केवल सिम्युलेटर / मॉक पाइपलाइन — **कोई लैब माप दावा नहीं किया गया**
- उद्धरण / बाद में Zenodo के लिए उपयुक्त; **नहीं** एक "यह बेंच पर काम करता है" रिलीज़
