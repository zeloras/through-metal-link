## 规则
本仓库中的每个技术决策必须能够追溯到“免费”列表（已过期的专利、论文）中的来源。活跃的专利仅供阅读——从中获取对问题的洞察力，但永远不要复制其声明（这对于在美国的商业化至关重要；请参阅项目中的专利地图）。

## 免费基础（已过期/废弃专利 = 公共领域）
- **US5982297**（航空航天公司，1997年）— 基本配方：通过墙壁的压电对，电力 + 双向数据。主要的食谱书。
- US5594705（Dynamotive，1994年）— 一个“声学变压器”通过船体。
- US6037704，US6127942（航空航天公司）— 为传感器供电，读取数据。
- **US7902943**（加州理工学院/喷气推进实验室，2019年因未缴纳维护费而失效）— Sherrit馈通：反射器，声学变压器。
- US9748870（加州理工学院/喷气推进实验室）— 通过墙壁的机械工作。
- **US9361877**（俄克拉荷马大学，失效）— 一个现代完整的收发器系统。
- US20100027379 / WO2008105947（DOE+RPI，废弃）— 从外部的载波 + 从内部的负载调制。

## 关键论文
- Lawry等人，IEEE TUFFC 2013（10.1109/TUFFC.2013.2550）— 50 W + 12.4 Mbit/s，63.5 mm钢。
- Sherrit等人，NASA NTRS 20080048150 — 一个通过墙壁供电的100 W灯。
- Yang等人，Sensors 2015（10.3390/s151229870）— 回顾，数字的最佳总结。
- Ji等人，Phys. Rev. Applied 21，014059（2024）— 超材料，2%→66%通过1 mm不锈钢（截至07.2026未找到专利）。

这些论文是**物理和专利卫生基线**。他们使用实验室换能器、键合和匹配的功率/比特率数字——而不是[QUICKSTART.md](../QUICKSTART.md)中的AliExpress Langevin +润滑剂BOM。将它们引用为存在证明；项目自己的通过标准存储在[experiments/](../../../experiments)中。
