# 安全须知

1. **压电元件上的高压。** 在谐振状态下，一旦二级驱动器上电，换能器端子上会有数十到数百伏的电压。接收侧的 TVS/稳压管必须在首次上电运行之前就接好。设备运行期间请勿触碰端子。
2. **市电。** 超声波清洗机的驱动器与市电直接电气相连。只能通过实验室电源 / 隔离变压器进行操作。本项目的半桥设计为在限流台式电源上运行，而非接在市电清洗机板子上运行。
3. **耳朵。** 人类听不到 40 kHz，但分谐波——以及动物——可以。对于任何非微功率的场景，请将发射器紧贴金属工作，不要向空气中辐射。大功率空气超声——绝不能在没有外壳的情况下开启。
4. **发热。** 兰杰文换能器在空载（未紧贴任何物体）满功率运行时，几分钟内就会过热。**默认规则：** 在提高功率之前，先将其夹紧到钢板（或牺牲块）上。唯一有意的例外是半桥的**短暂、低电流电气调试**（电源限流至 ~0.2 A，持续数秒而非数分钟，示波器探头接在开关节点上），详见 [hardware/driver/](../hardware/driver/README.md) ——这仍然不是自由空气中的功率运行。
5. **碎片飞溅。** 压电陶瓷是脆性材料；兰杰文螺栓拧得过紧或受到撞击 = 碎片飞溅。进行机械操作时请佩戴安全眼镜。
6. **一级与二级。** 一级扫频用 AD9833 输出的微弱正弦波（~0.6 Vpp）驱动 TX，电气上很温和；上述几乎所有危险都是在 IR2110 半桥和匹配变压器上电输出瓦特级功率时才真正出现的。
