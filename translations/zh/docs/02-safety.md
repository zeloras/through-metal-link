# 安全

> [English (primary)](../../../docs/02-safety.md) · [Русский](../../ru/docs/02-safety.md) · [Deutsch](../../de/docs/02-safety.md) · [Português](../../pt/docs/02-safety.md) · 中文 · [日本語](../../ja/docs/02-safety.md)

1. **压电器的高电压。** 在谐振时，换能器端子在第二级驱动器上线后会携带数十到数百伏的电压。接收侧的TVS/齐纳在第一次加电前就已安装。请勿在运行时触摸端子。
2. **市电。** 超声清洗器驱动器与市电是电气连接的。请仅通过实验室电源/隔离变压器工作。本项目的半桥设计是从电流限制的实验室电源供电，而不是从市电连接的清洗器板。
3. **听力。** 人类无法听到40 kHz的频率，但次谐波——以及动物——可以。在任何非平凡的功率下，请将发射器按压在金属上，而不是向空气辐射。强大的空气超声——请勿在没有外壳的情况下打开它。
4. **加热。** 兰杰文换能器在未加载（未按压在任何物体上）状态下运行，会在几分钟内在全功率下过热。**默认规则：** 在提高功率之前，请将其夹在板上（或牺牲块上）。唯一的故意例外是**简短的低电流电气启动**半桥（电源限制为~0.2 A，几秒钟而不是几分钟，范围在开关节点上）如[hardware/driver/](../../../hardware/driver/README.md)中所述——仍然不是自由空气功率运行。
5. **飞散物。**压电陶瓷是脆的；过紧的兰杰文螺栓或冲击=碎片。在机械工作期间请戴安全眼镜。
6. **第一阶段与第二阶段。** 第一阶段扫描驱动TX来自弱AD9833正弦（~0.6 Vpp）且电气上温和；几乎所有上述危险在IR2110半桥和匹配变压器上线以提供瓦特时变得现实。
