# 应用地图：谁需要这套技术栈，以及为什么

> [English (primary)](../../../docs/05-applications-map.md) · [Русский](../../ru/docs/05-applications-map.md) · [Deutsch](../../de/docs/05-applications-map.md) · [Português](../../pt/docs/05-applications-map.md) · [Español](../../es/docs/05-applications-map.md) · [Français](../../fr/docs/05-applications-map.md) · [Italiano](../../it/docs/05-applications-map.md) · [Polski](../../pl/docs/05-applications-map.md) · [Türkçe](../../tr/docs/05-applications-map.md) · [Українська](../../uk/docs/05-applications-map.md) · [Tiếng Việt](../../vi/docs/05-applications-map.md) · 中文 · [日本語](../../ja/docs/05-applications-map.md) · [한국어](../../ko/docs/05-applications-map.md) · [हिन्दी](../../hi/docs/05-applications-map.md)

平台栈：一条穿透盲壁的有源电力与数据通道——压电声学 / EMAT / 低频磁耦合。下面是：现实世界中哪里需要它，谁已经在做，以及留给我们的是什么。

## 1. 密封电池包（电动汽车、家用/工业储能）
- 痛点：热失控的早期检测——气体（CO₂、H₂、电解液蒸气）在起火前数分钟到数小时就已在包内出现；在 enclosure 上开传感器穿墙孔 = 丧失密封性和认证。
- 我们的方案：包内放置气体/温度节点，通过 2–3 mm 铝壁的压电对供电并回传遥测。零开孔。
- 谁已经在做：Liminal Insights——声学*外部诊断*（专利在于分析方法，而非通道本身）。没人在包*内部*卖节点。
- 细分成熟度：市场爆发式增长，货架却是空的。对平台而言——旗舰应用 #1。

## 2. 实验室设备：真空腔、低温恒温器、手套箱
- 痛点：每个进入真空腔的电馈通都是价值数百美元的法兰，也是泄漏源；在低温恒温器中，一根电缆 = 漏热。
- 我们的方案：腔内放传感器，通过钢壁用声波传输电力/数据；对于杜瓦瓶的真空夹层——低频磁耦合（对温度记录器来说 bit/s 的速率绰绰有余）。
- 谁已经在做：没有无线穿墙方案；实验室全靠馈通法兰过日子。
- 成熟度：开源的理想起步细分——实验室正是开源硬件的天然受众（TinyLev 路线）：他们无需认证就采购，还会在论文里引用你。

## 3. 食品生产：发酵罐、高压灭菌器（啤酒、葡萄酒、乳制品）
- 痛点：卫生规范讨厌穿墙孔（CIP 清洗、死区）；你想随时获知罐内的密度/温度/压力。
- 我们的方案：不锈钢罐内壁上的节点，从外部用手持扫描器或固定探头对轮询。
- 谁已经在做：普通的插入式传感器；没有无线穿墙方案。
- 成熟度：几乎在车库实验的触手可及范围内（任何精酿啤酒厂都是步行可达的试验场）。
- 物理注意事项：满载的罐体会给壁施加载荷——要针对满载容器重新扫频，并保持连续功率 ≲1 W/cm²；超过这个值，产品中会产生空化（CO₂ 脱气、异味、长期壁面侵蚀）——[理论](00-theory.md#effect-on-the-wall-and-the-media-behind-it)。

## 4. 管道、压力容器、工业 NDT
- 痛点：在不停机、不开孔的情况下监测内部腐蚀/参数；表面高温、有漆、脏污。
- 我们的方案：一把 EMAT"扫描枪"——零表面预处理直接贴在管道上，读取来自内部的被动谐振信标。
- 谁已经在做：夹装式超声流量计和测厚仪（成熟市场），但没有内部交互式信标。
- 成熟度：中等；需要 EMAT 分支（阶段 ~6）。

## 5. 油气/井下，以及核工业
- 谁已经在做：Metrol、Acoustic Data、Baker Hughes（井下，30 年，服务模式）；DOE/UNT/Westinghouse 研发（核燃料罐）。
- 诚实判断：已被占据且监管严格——我们不去那里，但它们的存在本身 = 证明这套物理能卖大钱。在 README 中用作参考。

## 6. 航海物流与水下结构
- 痛点：密封集装箱里"货物还活着吗"；从船体内侧获取数据。
- 谁已经在做：CSignum（低频电磁穿透水/舱壁）——混合理念中唯一的直接邻居。
- 成熟度：远期；对我们而言，目前只是一个思考方向。

## 优先级（做什么，按什么顺序）
1. **现在：** 在旗舰场景"实验室腔体 / 焊死盒子"上推进平台阶段 1–4（细分 #2——对开源最友好）。
2. **下一步：** 在细分 #3 的真实对象（啤酒厂发酵罐）上做演示——便宜、上镜、有真实用户。
3. **中期：** 电池场景（细分 #1）作为发表的旗舰案例；EMAT 分支用于细分 #4。

*被动成像（μ子射线照相）已拆分为独立项目——见知识库中的 muon-lab。*
