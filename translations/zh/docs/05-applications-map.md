# 应用地图：谁需要这个技术栈，为什么

> [English (primary)](../../../docs/05-applications-map.md) · [Русский](../../ru/docs/05-applications-map.md) · [Deutsch](../../de/docs/05-applications-map.md) · [Português](../../pt/docs/05-applications-map.md) · [Español](../../es/docs/05-applications-map.md) · [Français](../../fr/docs/05-applications-map.md) · [Italiano](../../it/docs/05-applications-map.md) · [Polski](../../pl/docs/05-applications-map.md) · [Türkçe](../../tr/docs/05-applications-map.md) · [Українська](../../uk/docs/05-applications-map.md) · [Tiếng Việt](../../vi/docs/05-applications-map.md) · 中文 · [日本語](../../ja/docs/05-applications-map.md) · [한국어](../../ko/docs/05-applications-map.md) · [हिन्दी](../../hi/docs/05-applications-map.md)

平台栈：通过盲墙的主动电力和数据通道 —— 压电声学 / EMAT / 低频磁性。下面：在现实世界中，这是需要的，谁已经在那里，以及还有什么留给我们。

## 1. 密封电池包（EV，家庭/工业能量存储）
- 痛点：早期检测热失控 —— 气体（CO₂，H₂，电解液蒸汽）在包内出现几分钟到几小时前就会发生火灾；传感器穿透封闭体 = 损失密封和认证。
- 我们的栈：包内的气体/温度节点，通过 2-3 mm 铝的压电对实现电力和遥测。零孔。
- 谁已经在那里：Liminal Insights —— 从外部进行声学 * 诊断（分析方法的专利，不是通道）。没有人出售包内的节点。
- 市场成熟度：市场正在爆炸性增长，货架是空的。对于平台 —— 展示应用 #1。

## 2. 实验室设备：真空室，低温器，手套箱
- 痛点：每个电气馈通到真空室都是一个价值数百美元的法兰盘和泄漏源；在低温器中，电缆 = 热泄漏。
- 我们的栈：室内传感器，通过钢墙的声音实现电力和数据传输；对于真空三明治的杜瓦 —— 低频磁性（每秒位数足以用于 T- 日志记录器）。
- 谁已经在那里：没有人拥有无线穿墙；实验室依赖于馈通法兰。
- 成熟度：这是开源的理想起始领域 —— 实验室正是开源硬件的受众（TinyLev 路径）：他们在没有认证的情况下购买，并在论文中引用您。

## 3. 食品生产：发酵罐，高压釜（啤酒，葡萄酒，乳制品）
- 痛点：卫生法规禁止穿透（CIP 清洗，死区）；您希望随时了解罐内的密度/温度/压力。
- 我们的栈：在不锈钢罐的内壁上安装一个节点，使用手持式扫描仪或固定对从外部进行轮询。
- 谁已经在那里：普通的插入式传感器；没有无线穿墙解决方案。
- 成熟度：从车库测试中可以轻松实现（任何手工酿酒厂都是一个可行的测试场）。
- 物理注意事项：满罐会加载墙壁 —— 重新扫描满容器，并保持连续电力 ≲1 W/cm²；超过该值，会发生介质的空化（CO₂ 脱气，异味，长期墙体侵蚀） —— [理论](00-theory.md#effect-on-the-wall-and-the-media-behind-it)。

## 4. 管道，压力容器，工业无损检测
- 痛点：在不关闭或穿透的情况下监测腐蚀/参数内部；表面热，漆，脏。
- 我们的栈：EMAT “扫描枪” —— 将其按在管道上，零表面准备，读取内部的被动共振信标。
- 谁已经在那里：夹式超声波流量计和厚度计（一个成熟的市场），但内部没有交互式信标。
- 成熟度：中等；需要 EMAT 分支（第 6 阶段）。

## 5. 石油和天然气/下井和核能
- 谁已经在那里：Metrol，Acoustic Data，Baker Hughes（下井，30 年，服务模式）；DOE/UNT/Westinghouse R&D（核能贮罐）。
- 诚实的判决：占据和严格监管 —— 我们不去那里，但他们的存在 = 证明这个物理学可以卖出大量的钱。用作 README 中的参考。

## 6. 海事物流和水下结构
- 痛点：“货物是否存活”在密封容器中；从船体内侧获取数据。
- 谁已经在那里：CSignum（LF EM 通过水/壁） —— 唯一直接的混合理念邻居。
- 成熟度：长期；对于我们来说，现在只是一个思考方向。

## 优先顺序（要做什么，以什么顺序）
1. **现在：** 平台阶段 1-4 在展示场景 “实验室室/焊接盒”（领域 #2 —— 最开放的开源）。
2. **下一步：** 在领域 #3 的实物上演示（一个酿酒厂罐） ——廉价，照片效果好，真正的用户。
3. **中期：** 电池场景（领域 #1）作为出版物的旗舰案例；EMAT 分支用于领域 #4。

*被动视觉（μ子辐射图）已分离到一个单独的项目 ——请参阅知识库中的 muon-lab。*
