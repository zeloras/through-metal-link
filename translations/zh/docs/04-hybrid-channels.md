# 混合通道：屏障 → 物理 → 数字

原理（"穿透悖论"的推论）：波穿过屏障的程度，恰好等于它与屏障弱相互作用的程度——这就是为什么不存在万能通道。平台不追求单一通道；对每种屏障，它选择屏障对其透明、接收端又与之共振"贪婪"匹配的物理机制。

## 通道选择表

| 屏障 | 工作通道 | 预期（数量级） | 备注 |
|---|---|---|---|
| 钢/铝 1–60 mm，可接触 | 压电声学（我们的主通道） | 瓦级；kbit/s（MHz 模式下可达 Mbit/s） | 需要声学耦合（耦合脂/环氧胶） |
| 金属：脏污、有漆、高温、不宜接触 | EMAT（磁场 → 壁内声波） | mW；kbit/s；间隙可达 ~3 mm | 仅限导电壁；传数据，不传功率 |
| 完全无压电的铁磁壁 | 磁致伸缩（线圈直接驱动钢壁本身） | 微量；bit/s–kbit/s | 实验性分支，测试成本低 |
| 真空双层壁（保温瓶、低温恒温器、杜瓦瓶） | 低频磁场（数十至数百 Hz） | µW–mW；bit/s | 趋肤效应：钢中 δ≈0.6 mm @1 kHz——需降低频率 |
| 非金属：玻璃、塑料、陶瓷 | 压电声学（比金属更容易） | 瓦级；kbit/s | 普通射频通常也能穿透——先检查这个 |
| 带橡胶/泡沫层的壁、复合材料 | 老实说：几乎是死路 | — | 吸收层吃掉一切；变通办法是找一块无涂层的位置 |
| 壁后有液体（满罐） | 压电声学，性能下降 | 功率 − 几 dB；振铃更短 | 液体负载会偏移/阻尼共振——需对满容器重新扫频；保持连续强度 ≲1 W/cm² 以避免空化（[理论](00-theory.md#effect-on-the-wall-and-the-media-behind-it)） |
| 声学路径中有气泡液体 | 结构性变通方案 | — | 将接收器贴在壁上，让液体不进入声学路径 |

## 混合节点架构

- 功率层：谐振压电对（阶段 1–4）。
- 非接触数据层：EMAT 探头作为可拆卸"扫描枪"（约阶段 6）。
- 备用层：用于真空夹层的低频线圈（按需启用）。
- 发现协议（docs/03）从"扫频"扩展为"扫物理"：ping 压电 → ping EMAT → ping 低频；节点自行选择能穿透的通道，并报告它看到的屏障类型。

## 按通道的典型应用

1. **密封电池包（电动车/储能）：** 灌封外壳内的温度/气体传感器；通过 2–3 mm 铝壁用压电对传输功率+数据。市场正蓬勃发展，而穿透电池外壳 = 认证地狱。
2. **低温恒温器/杜瓦瓶：** 内部温度记录器，每分钟通过低频磁场经真空夹层发送一个比特包。声学根本无法企及——这正是混合方案不可替代之处。
3. **带压管道/高压釜：** EMAT 扫描器贴在高温有漆管道上，零表面处理——读取内部无源谐振信标。
4. **发酵罐（啤酒/葡萄酒，不锈钢）：** 罐内密度/温度传感器，无需任何穿透——卫生法规喜欢没有孔洞。
5. **海运集装箱/保险箱：** "货物还活着吗"——通过瓦楞钢板的压电对，用手持扫描器轮询。

## 任何层都无法解决的局限
功率——仅限接触式压电（EMAT 和低频磁场弱好几个数量级）。复合材料/橡胶内衬壁不在平台覆盖范围内。低频通道速度为比特每秒——那是遥测，不是流式传输。
