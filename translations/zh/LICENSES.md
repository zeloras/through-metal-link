该方案的目标：项目完全开放，任何人都可以分叉并在其基础上进行建设（包括商业用途），同时通过法律和程序手段将专利诉讼风险降至最低。

## 方案（三层；完整文本在 [LICENSES/](../../LICENSES) 中）

|---|---|---|---|

| `hardware/` | CERN-OHL-W v2 | [LICENSES/CERN-OHL-W-2.0.txt](../../LICENSES/CERN-OHL-W-2.0.txt) | §7.1：每个许可人的专利许可（制造/已制造/使用/销售/进口...）- 但仅适用于被许可源代码必然侵犯的权利要求；§7.2：专利诉讼（包括试图无效他人的专利）终止 **所有** 许可下的权利 |

代码文件带有 SPDX 头（Apache-2.0）；机器可读的覆盖范围映射是 [REUSE.toml](../../REUSE.toml)。版权行位于 [NOTICE](../../NOTICE)；根 [LICENSE](../../LICENSE) 是指向此方案的指针。

**为什么选择 CERN-OHL-W，而不是 S 或 P。** W 是中间立场：设计及其修改必须在任何分发中保持开放，但设计构建的产品可以是商业和专有的 - 这保持了来自 docs/05 的开放领域（实验室，酿酒厂，电池包）。S（强 copyleft）将关闭嵌入的门；P（宽容）将允许关闭分叉。向 S 紧缩是内置于许可证本身：§8.3 允许任何人将 W 许可的材料视为 S 许可（只要满足可用组件条件）- 无需许可。放松（向 P 或其他许可证）相比，只有在所有材料属于单个作者时才有可能；在第一次外部贡献之后 - 只有在每个贡献者的同意下。

**项目名称。**“through-metal-link”不是注册商标；许可证本身不授予名称的权利（Apache §6，CC-BY §2(b)(2)，CERN-OHL-W §8.2）。对项目进行事实上的引用（“基于 through-metal-link”）对任何人都是免费的；具有不兼容更改的分叉被要求以自己的名称进行交付。

## 这保护了什么 - 以及它不能保护什么（诚实）

**它保护以下内容：**
1. **来自贡献者的诉讼。** 每个贡献者都自动授予其贡献的专利权（Apache §3，CERN-OHL §7.1 和 CONTRIBUTING 中的文档）。一场诉讼会让原告付出巨大的代价：在 Apache-2.0 下，他们会失去代码的专利许可；在 CERN-OHL-W 下，他们会失去硬件层的所有权利（§7.2 - 即使是尝试挑战他人的专利）。
2. **硬件分叉的私有化。** CERN-OHL-W 强制任何分发（产品或源代码的传递）的人发布其设计修改 - 改进会流回开放层并成为先前的艺术。（一个抽屉分叉，从未传递给第三方，没有发布义务 - 与任何 copyleft 下一样。）
3. **其他人的 *未来* 专利。** 发布的所有内容都带有日期，破坏了后续申请的新颖性：对于在我们的提交日期之前描述的解决方案，不能授予有效的专利。对于在我们的发布之前提交的申请，这不起作用 - 对于这些，唯一的盾牌是过期专利层（见下文）。

**它不保护以下内容：**
- **已经存在的第三方专利。** 没有任何许可可以做到这一点。对抗它们的方法是 docs/01-prior-art.md 中的工程学科：仅从过期层（公共领域）构建，不要实施实时索赔（RPI OFDM/全双工，Drexel - 直到 ~2032，仅限美国），并将每个设计决策追溯到免费来源。这不是保证，但这正是使诉讼变得无用的做法。
- 一个分叉的商业生产版本执行自己的 FTO（自由操作）分析，适用于其自己的管辖权和设计 - 存储库不做任何专利表示（所有三个许可中的免责声明）。

## 防御性出版协议（在存储库公开时执行）

每个发布的结果都是带有日期的先前艺术作品，阻止所有后续第三方针对相同解决方案的申请：

1. 打开存储库，包括其完整的 Git 历史记录（提交 = 时间戳）。
2. 快照到 **Zenodo** → DOI：一个具有法律意义的日期的独立存档，可以在论文中引用。
3. 在 **Software Heritage** (archive.softwareheritage.org - 永久镜像) 中固定它。
4. 每个完成的实验 `experiments/NNN` - 带有日期、数字和图表：这是特定技术解决方案的发布。
5. 重大里程碑（第一瓦、第一个节点）- 一篇外部的文章（Hackaday.io / arXiv / 博客）：传播范围越广，先前艺术作品的状态越强。

## 对贡献者

规则位于 [CONTRIBUTING.md](CONTRIBUTING.md)：DCO 签署，入站 = 出站，贡献的显式专利授予，无论目录如何，设计决策的可追溯性到免费的先前艺术。

在它公开之前，存储库保持私有 - 在获得第一个可复制的结果之前发布会削弱科学和专利立场。
