# ADR-0001: Выбор частотного режима для этапа 1

> [English (primary)](../../../../docs/decisions/0001-vybor-chastotnogo-rezhima.md) · Русский · [Deutsch](../../../de/docs/decisions/0001-vybor-chastotnogo-rezhima.md) · [Português](../../../pt/docs/decisions/0001-vybor-chastotnogo-rezhima.md)

- Статус: ПРИНЯТО (пересмотр после этапа 2)
- Дата: 2026-07-24

## Контекст
Два режима (см. docs/00-theory.md): A — 28–40 кГц на ланжевенах, B — 0.6–1 МГц на дисках с толщинным резонансом стенки.

## Решение
Этап 1–2 — режим A. Причины: дешевле ($10–30/шт), мощнее (единицы Вт против сотен мВт), терпимее к настройке (широкий резонанс), драйвер собирается из полумоста на IR2110. Режим B — после получения первых ватт, как отдельная ветка для данных на высокой скорости.

## Последствия
Данные на этапе 3 будут медленными (кбит/с) — для сенсорного узла достаточно. АЦП ADS1115 (860 SPS) хватает для огибающей на 40 кГц после выпрямителя, но не для прямой оцифровки — прямую оцифровку отложить до режима B (нужен другой АЦП).

Этап 1 (свип-карта) использует только слабый DDS-драйв; этап 2 (ватты) — отдельный эксперимент и подъем ([experiments/002](../../../../experiments/002-watts-3mm-steel/README.md)). Полосы мощности симулятора остаются целями до измерения 002.
