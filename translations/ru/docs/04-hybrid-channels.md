# Гибридные каналы: барьер → физика → числа

> [English (primary)](../../../docs/04-hybrid-channels.md) · Русский · [Deutsch](../../de/docs/04-hybrid-channels.md) · [Português](../../pt/docs/04-hybrid-channels.md) · [Español](../../es/docs/04-hybrid-channels.md) · [Français](../../fr/docs/04-hybrid-channels.md) · [Italiano](../../it/docs/04-hybrid-channels.md) · [Polski](../../pl/docs/04-hybrid-channels.md) · [Türkçe](../../tr/docs/04-hybrid-channels.md) · [Українська](../../uk/docs/04-hybrid-channels.md) · [Tiếng Việt](../../vi/docs/04-hybrid-channels.md) · [中文](../../zh/docs/04-hybrid-channels.md) · [日本語](../../ja/docs/04-hybrid-channels.md) · [한국어](../../ko/docs/04-hybrid-channels.md) · [हिन्दी](../../hi/docs/04-hybrid-channels.md)

Принцип (следствие «парадокса врезки»): волна проходит через барьер ровно настолько, насколько слабо с ним взаимодействует — именно поэтому универсального канала не существует. Платформа не гонится за одним каналом; для каждого барьера она выбирает физику, которой барьер прозрачен, а приёмник резонансно «прожорлив».

## Таблица выбора канала

| Барьер | Рабочий канал | Ожидаемый результат (порядки величин) | Примечания |
|---|---|---|---|
| Сталь/алюминий 1–60 мм, контакт возможен | Пьезоакустика (наш основной) | ватты; кбит/с (до Мбит/с в МГц-режиме) | нужен акустический контакт (смазка/эпоксид) |
| Металл: грязный, окрашенный, горячий, контакт нежелателен | EMAT (магнитное поле → звук в стенке) | мВт; кбит/с; зазор до ~3 мм | только проводящие стенки; данные, не мощность |
| Ферромагнитная стенка вообще без пьезо | Магнитострикция (катушка раскачивает саму сталь) | крохи; бит/с–кбит/с | экспериментальная ветка, дёшево проверить |
| Двойная стенка с вакуумом (термос, криостат, дьюар) | НЧ-магнитика (десятки–сотни Гц) | мкВт–мВт; бит/с | скин-эффект: в стали δ≈0,6 мм @1 кГц — частоту вниз |
| Неметалл: стекло, пластик, керамика | Пьезоакустика (проще, чем металл) | ватты; кбит/с | + обычный РЧ часто тоже проходит — проверьте сначала; числа и вердикты по материалам: [06-materials](../../../docs/06-materials.md) |
| Стенка со слоем резины/пены, композит | Честно: почти тупик | — | поглотитель съедает всё; обход — найти пятно без покрытия |
| Жидкость за стенкой (полный бак) | Пьезоакустика, деградированная | мощность − несколько дБ; короче «звон» | жидкостная нагрузка сдвигает/демпфирует резонанс — переснять свип-карту на полной ёмкости; держать непрерывную интенсивность ≲1 Вт/см², чтобы не допустить кавитации ([теория](00-theory.md#влияние-на-стенку-и-среду-за-ней)) |
| Пузырящаяся жидкость на акустическом пути | Архитектурный обход | — | ставить приёмник на стенку, жидкость убрать из пути |

## Архитектура гибридного узла

- Слой питания: пьезопара на резонансе (стадии 1–4).
- Бесконтактный слой данных: EMAT-головка как съёмный «сканер-пистолет» (стадия ~6).
- Резервный слой: НЧ-катушки для вакуумных сэндвичей (когда задача требует).
- Протокол обнаружения (docs/03) расширяется от «свип по частоте» к «свип по физике»: пинг пьезо → пинг EMAT → пинг НЧ; узел сам выбирает канал, который проходит, и сообщает, какой барьер видит.

## Примеры применений по каналам

1. **Герметичные батарейные сборки (EV/накопители):** датчик T/газа внутри залитого корпуса; питание+данные через пьезопару сквозь 2–3 мм алюминия. Рынок booming, а врезка в батарейный корпус = сертификационный ад.
2. **Криостат/дьюар:** температурный логгер внутри, шлёт бит-пакет раз в минуту через НЧ-магнитику сквозь вакуумную рубашку. Принципиально недоступно акустике — здесь гибрид незаменим.
3. **Трубопровод/автоклав под давлением:** EMAT-сканер, прижатый к горячей окрашенной трубе с нулевой подготовкой поверхности — читает пассивный резонансный маячок изнутри.
4. **Бродильные танки (пиво/вино, нержавеющая сталь):** датчик плотности/T внутри танка без единой врезки — санитарные нормы обожают отсутствие отверстий.
5. **Морской контейнер/сейф:** «жив ли груз» — пьезопара через гофрированную сталь, опрос ручным сканером.

## Ограничения, не решаемые ни одним слоем
Мощность — только контактный пьезо (EMAT и НЧ-магнитика на порядки слабее). Композитные/резиновые стенки вне платформы. Скорость НЧ-канала — биты в секунду: это телеметрия, не поток.
