Первый датированный публичный снимок открытой гаражной платформы для ультразвуковой передачи питания и данных через сплошные металлические стенки.

## Что представляет собой этот тег
- Документация + ПО + BOM + протоколы экспериментов на момент помеченного коммита
- Только симулятор / макетный конвейер — **лабораторные измерения не заявляются**
- Пригоден для цитирования / последующего Zenodo; **не** является релизом «работает на стенде»

## Включено
- Честность README стадии 0 (симулятор ≠ лабораторные данные)
- QUICKSTART + BOM стадии 1
- Свип-карта `--mock` и симулятор канала
- Шаблоны экспериментов 001 / 002
- Вопросы по сборке: [Discussion #35](https://github.com/zeloras/through-metal-link/discussions/35)
- Аппаратный баунти: [Issue #5](https://github.com/zeloras/through-metal-link/issues/5)

## Не включено
- Измеренные CSV / фото / видео для экспериментов 001 / 002
- Гарантированные ватты через сталь
