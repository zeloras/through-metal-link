# Предшествующий уровень техники: на что мы опираемся

## Правило
Каждое техническое решение в этом репозитории должно быть возводимо к источнику из списка «свободных» (истёкшиеся патенты, статьи). Действующие патенты — только для чтения: черпайте из них понимание проблем, но никогда не копируйте их формулы изобретения (это важно для коммерциализации в США; см. патентную карту проекта).

## Свободный фундамент (истёкшиеся/покинутые патенты = общественное достояние)
- **US5982297** (Aerospace Corp, 1997) — базовый рецепт: пьезопара через стенку, питание + двунаправленные данные. Главная поваренная книга.
- US5594705 (Dynamotive, 1994) — «акустический трансформатор» через обшивку.
- US6037704, US6127942 (Aerospace Corp) — питание датчиков, считывание данных обратно.
- **US7902943** (Caltech/JPL, утратил силу из-за неуплаты пошлин за поддержание в 2019) — Sherrit feed-through: отражатель, акустический трансформатор.
- US9748870 (Caltech/JPL) — механическая работа через стенку.
- **US9361877** (Univ. Oklahoma, утратил силу из-за неуплаты пошлин за поддержание) — современная полная приёмопередающая система.
- US20100027379 / WO2008105947 (DOE+RPI, покинут) — несущая снаружи + нагрузочная модуляция изнутри.

## Ключевые статьи
- Lawry et al., IEEE TUFFC 2013 (10.1109/TUFFC.2013.2550) — 50 Вт + 12.4 Мбит/с, 63.5 мм стали.
- Sherrit et al., NASA NTRS 20080048150 — лампа мощностью 100 Вт, запитанная через стенку.
- Yang et al., Sensors 2015 (10.3390/s151229870) — обзор, лучший свод чисел.
- Ji et al., Phys. Rev. Applied 21, 014059 (2024) — метаматериал, 2%→66% через 1 мм нержавейки (патент не найден по состоянию на 07.2026).

Эти статьи — **физический и патентно-гигиенический базис**. Их числа по мощности/скорости получены на лабораторных преобразователях, с приклейкой и согласованием — а не на ланжевенах с AliExpress и смазке из [QUICKSTART.md](../QUICKSTART.md). Цитируйте их как доказательства реализуемости; собственные проходные баллы проекта живут в [experiments/](../experiments/).

## Что мы не копируем, пока действует
Старое ядро этого списка — только США и истекает примерно в 2032–2033, и стадии 1–4 не требуют ничего из него: OFDM с поднесущими, размещёнными так, чтобы обходить гармоники силового канала (RPI US9054826); полнодуплексная схема «АМ-канал вниз + нагрузочная модуляция вверх + слежение за частотой» как единое решение (RPI US9455791); конформные преобразователи для криволинейных поверхностей по подходу Drexel (US10594409). Семейства ниже — не из этого числа: одно читается на голом силовом канале стадии 2, а другое действует в Европе до 2039.

**Добавлено поиском 2026-08 (статусы — флаги Google Patents; перепроверьте в USPTO Patent Center / EP-реестре перед любым коммерческим использованием):**
- **US8594572B1** (ВМС США, приоритет 2011-06, пошлина за 12 лет уплачена 2025, действует до 2032-01, только США) — формула 1: «стенка + источник питания + преобразователь, превращающий ток в ультразвук через стенку + преобразователь, превращающий обратно + запитываемое электронное устройство», без ограничений по частоте, материалу или толщине: буквально читается на голый силовой канал в США. Патент Welle US5982297 (1997) раскрывает ту же компоновку, так что истёкший слой — это же и основание для оспаривания недействительности; тем не менее, коммерческий форк для США должен получить заключение по FTO.
- **EP3723304B1** (ABB, приоритет 2019-04, выдан 2023-08, поддерживается **только в DE и GB** — CH утратил силу 2024-04, других валидаций в прочитанных данных реестра не найдено; до 2039-04; нет американского члена) — «акустический волновод» (стенка сосуда в описании), передающий питание *и* обратный отклик данных на платформу датчика, **где спектр, несущий питание, ниже спектра данных**. Это ограничение было импортировано из зависимого пункта формулы во время делопроизводства для получения гранта, и это наш обход: планируемый канал вверх — нагрузочная модуляция на *той же* несущей 40 кГц ([docs/03](03-discovery-protocol.md)) — боковые полосы вокруг силовой несущей, а не более высокочастотная полоса (чтение формулы, а не заключение по FTO). Не добавляйте отдельную более высокочастотную несущую данных (собственный пример ABB: 200–300 кГц данных поверх низкочастотного питания) к силовому каналу режима A в продукте для DE/GB.
- **Семейство Ultrapower** (приоритет 2014-03, до 2035-03): US10295500B2 — датчик внутри металлической *трубы*, приёмопередатчик снаружи, **выпуклые/вогнутые** решётки преобразователей; US10684260B2 / US10948457B2 — металлический стержень *через* стенку. Мы используем плоские проточенные площадки и без стержня.
- **US9602221B2** (Zackat Inc.; события залога/уступки называют Anelto Inc. / Instant Care Inc.; приоритет 2014-03, восстановлен 2021, пошлина уплачена 2024, до 2035-10, США) — формула 1: ультразвуковой передатчик на «устройстве класса 1» внутри зоны взрывоопасности, приёмник снаружи, сигнал тревоги удалённому оператору; **независимая формула 14 снимает ограничение по устройству класса 1** (любой датчик внутри зоны взрывоопасности + ультразвуковой канал + сигнал тревоги). Релевантно, только если узел когда-либо подаёт сигналы тревоги из опасной зоны — повод держать любое такое применение на уровне макета в США.
- Тангенциальные, отмечены: GE US9146266B2 (телеметрия через конструкции энергогенерации, до 2033), UNT US11415555 (пассивные SAW/BAW через стенку), CEA EP4080791B1 (оптимизация частоты сканированием импеданса), RPI US9331879B2 (MIMO), US9505031B2 (пружинный корпус). Формула 1 RPI US9455791B2 действительно содержит нагрузочную модуляцию на MOSFET внутреннего преобразователя — но только в связке с дифференциальным АМ-каналом вниз, синхронизацией выборок по последовательности Баркера и алгоритмом шага/слежения по частоте; [docs/03](03-discovery-protocol.md) намеренно не содержит ничего из АМ/Баркер-канала вниз, и вся эта комбинация не должна быть реализована, пока патент действует.
- Свободные, дополнительно подтверждено: Progeny/General Dynamics US20120127833A1 (раздельные частоты питания/данных — **покинут**), RPI/DOE US20100027379A1 (нагрузочная модуляция канала вверх — покинут).
