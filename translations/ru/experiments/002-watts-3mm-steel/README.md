# Эксперимент 002: Первые ватты сквозь 3 мм стали (ЗАПЛАНИРОВАН)

- **Этап:** 2 (мощность в известную нагрузку на резонансе, найденном в [001](../001-sweep-map-3mm-steel/README.md)).
- **Цель:** измерить реальную мощность постоянного тока, переданную сквозь 3 мм стали, с полумостовым драйвером и согласующим трансформатором.
- **Гипотеза:** с парой ланжевенов из одной партии, контактом через смазку+струбцину (или эпоксидку) и настроенным согласующим трансформатором достижимо ≥0,5 Вт в резистивную нагрузку на пике этапа 1. (Многоваттные/киловаттные цифры из литературы получены на других преобразователях и с другой склейкой — считайте их потолком, а не проходным баллом.)
- **Предусловия:**
  - Эксперимент 001 закрыт (воспроизводимый пик, частота записана).
  - TVS установлен в RX-тракте до подачи питания на драйвер ([docs/02-safety.md](../../docs/02-safety.md)).
  - Соблюдена последовательность запуска драйвера ([hardware/driver/README.md](../../hardware/driver/README.md)).
- **Стенд (минимум):**
  - TX: Pi → AD9833 (меандр) → формирователь мёртвого времени → полумост IR2110 → согласующий трансформатор → ланжевен, прижатый струбциной к пластине ([sch1](../../hardware/schematics/sch1-driver-halfbridge.png)).
  - Стенка: 3 мм стали, способ контакта зафиксирован (смазка+струбцина / эпоксидка / другое).
  - RX: ланжевен → мост Шоттки → известный R_load (мощной резистор) и/или светодиод; измерять V_dc и I_dc после моста (топология [sch2](../../hardware/schematics/sch2-receiver-stage1.png), нагрузка вместо только АЦП).
- **Процедура (набросок):**
  1. Электрический запуск при ограничении БП 0,2 А без заявления об акустической мощности.
  2. Прижать TX/RX струбциной, выставить частоту возбуждения на пик эксперимента 001.
  3. Плавно поднимать ограничение тока; записывать V/I БП, температуру MOSFET/трансформатора, V_dc и I_dc на нагрузке.
  4. P_load = V_dc · I_dc. Опционально: фото с коротким демо-светодиодом, когда P_load уже известна.
  5. Повторить один раз после остывания; пиковая частота может дрейфовать с температурой — перепроверить мини-свипом, если мощность падает.
- **Критерии успеха:**
  1. P_load ≥ 0,5 Вт сквозь 3 мм стали на задокументированной частоте и способе контакта.
  2. Два прогона сходятся по P_load в пределах ~20% при той же струбцине/смазке (стабильность порядка величины, а не метрологическая точность).
  3. Фото светодиода (или иной нагрузки) + CSV/лог, прикреплённые из этого файла в `data/`.
- **Отрицательный результат — тоже данные:** если P_load остаётся ≪ 0,5 Вт, записать Δf пары (из 001), способ контакта, число витков трансформатора и осциллограммы — это вход для следующего ADR, а не повод молча править симулятор.
