# Эксперимент 002: Первые Ватты Через 3 мм Сталь (ПЛАНИРУЕТСЯ)

> [English (primary)](../../../../experiments/002-watts-3mm-steel/README.md) · Русский · [Deutsch](../../../de/experiments/002-watts-3mm-steel/README.md) · [Português](../../../pt/experiments/002-watts-3mm-steel/README.md) · [中文](../../../zh/experiments/002-watts-3mm-steel/README.md) · [日本語](../../../ja/experiments/002-watts-3mm-steel/README.md)

- **Стадия:** 2 (питание в известную нагрузку на резонансе, найденном в [001](../001-sweep-map-3mm-steel/README.md)).
- **Цель:** измерить реальную мощность постоянного тока, передаваемую через 3 мм сталь с помощью полумостового драйвера и согласующего трансформатора.
- **Гипотеза:** с помощью пары ланжевенов одного выпуска, контакта через смазку+струбцину (или эпоксидную смолу) и настроенного согласующего трансформатора достижимо ≥0,5 Вт в резистивную нагрузку на пике первой стадии. (Литературные данные о нескольких ваттах/киловаттах использовали разные преобразователи и методы крепления — рассматривайте их как потолок, а не как проходной балл.)
- **Предварительные условия:**
  - Эксперимент 001 завершён (воспроизводимый пик, частота записана).
  - TVS установлен в цепи RX до подачи питания на драйвер ([docs/02-safety.md](../../docs/02-safety.md)).
  - Выполнена последовательность включения драйвера ([hardware/driver/README.md](../../hardware/driver/README.md)).
- **Настройка (минимальная):**
  - TX: Pi → AD9833 квадрат → формирователь мёртвого времени → IR2110 полумост → согласующий трансформатор → ланжевен, прижатый к пластине струбциной ([sch1](../../hardware/schematics/sch1-driver-halfbridge.png)).
  - Стена: 3 мм сталь, метод контакта записан (смазка+струбцина / эпоксидная смола / другой).
  - RX: ланжевен → мост Шоттки → известная R_load (мощный резистор) и/или светодиод; измерить V_dc и I_dc после моста (топология [sch2](../../hardware/schematics/sch2-receiver-stage1.png), нагрузка вместо только ADC).
- **Процедура (конспект):**
  1. Электрический запуск при ограничении тока источника питания 0,2 А без заявления об акустической мощности.
  2. Зафиксировать TX/RX струбциной, установить частоту управления на пик эксперимента-001.
  3. Постепенно повышать ограничение тока; записывать V/I источника питания, температуру MOSFET/трансформатора, V_dc и I_dc на нагрузке.
  4. P_load = V_dc · I_dc. Необязательно: короткая демонстрационная фотография светодиода после определения P_load.
  5. Повторить один раз после охлаждения; пиковая частота может дрейфовать с температурой — перепроверить мини-свипом, если мощность падает.
- **Критерии успеха:**
  1. P_load ≥ 0,5 Вт через 3 мм сталь на задокументированной частоте и методе контакта.
  2. Два запуска сходятся по P_load в пределах ~20% при одинаковой струбцине/смазке (стабильность порядка величины, а не метрологический класс пока).
  3. Фотография светодиода (или другой нагрузки) + CSV/журнал, связанный с этим файлом под `data/`.
- **Неудача — это данные:** если P_load остаётся ≪ 0,5 Вт, записать Δf пары (из 001), метод контакта, число витков трансформатора и осциллограммы — это вход для следующего ADR, а не повод молча править симулятор.
