# Эксперимент 002: Первые Ватты Через 3 мм Сталь (ПЛАНИРУЕТСЯ)

> [English (primary)](../../../../experiments/002-watts-3mm-steel/README.md) · Русский · [Deutsch](../../../de/experiments/002-watts-3mm-steel/README.md) · [Português](../../../pt/experiments/002-watts-3mm-steel/README.md)

- **Стадия:** 2 (питание в известную нагрузку на резонансе, найденном в [001](../../../../experiments/001-sweep-map-3mm-steel/README.md)).
- **Цель:** измерить реальную мощность постоянного тока, передаваемую через 3 мм сталь с помощью полумостового драйвера и согласующего трансформатора.
- **Гипотеза:** с помощью пары ланжевенов одного выпуска, контакта с помощью смазки и зажима (или эпоксидной смолы) и настроенного согласующего трансформатора достижимо ≥0,5 Вт в резистивную нагрузку на пике первой стадии. (Литературные данные о нескольких ваттах/киловаттах использовали разные преобразователи и методы крепления — рассматривайте их как потолок, а не как планку.)
- **Предварительные условия:**
  - Эксперимент 001 завершен (репроизводимый пик, записанная частота).
  - Ограничитель напряжения установлен в цепи RX до подачи питания драйверу ([docs/02-safety.md](../../docs/02-safety.md)).
  - Выполнена последовательность включения драйвера ([hardware/driver/README.md](../../hardware/driver/README.md)).
- **Настройка (минимальная):**
  - TX: Pi → AD9833 квадрат → формирователь мёртвого времени → IR2110 полумост → согласующий трансформатор → ланжевен, зажатый к пластине ([sch1](../../hardware/schematics/sch1-driver-halfbridge.png)).
  - Стена: 3 мм сталь, метод контакта записан (смазка+зажим / эпоксидная смола / другой).
  - RX: ланжевен → мост Гретца/Шоттки → известная нагрузка R_load (пOWERный резистор) и/или светодиод; измерить V_dc и I_dc после моста ([sch2](../../hardware/schematics/sch2-receiver-stage1.png) топология, нагрузка вместо ADC-only).
- **Процедура (конспект):**
  1. Электрический запуск при ограничении тока источника питания 0,2 А без заявления об акустической мощности.
  2. Зажать TX/RX, установить частоту управления на пик эксперимента-001.
  3. Постепенно увеличить ограничение тока; записать напряжение и ток источника питания, температуру MOSFET/трансформатора, V_dc и I_dc на нагрузке.
  4. P_load = V_dc · I_dc. Необязательно: короткая демонстрационная фотография светодиода после определения P_load.
  5. Повторить один раз после охлаждения; пиковая частота может сдвигаться с температурой — повторно проверить с помощью мини-просканирования, если мощность падает.
- **Критерии успеха:**
  1. P_load ≥ 0,5 Вт через 3 мм сталь на задокументированной частоте и методе контакта.
  2. Два запуска согласны с P_load в пределах ~20% при одинаковом зажиме/куплинге (порядок величины стабильности, не метрологического класса пока).
  3. Фотография светодиода (или другой нагрузки) + CSV/журнал, связанный с этим файлом под `data/`.
- **Неудача — это данные:** если P_load остается ≪ 0,5 Вт, записать разницу частот пары (из 001), метод контакта, количество витков трансформатора и формы сигналов — это вход для следующего АDR, а не причина молчаливо редактировать симулятор.
