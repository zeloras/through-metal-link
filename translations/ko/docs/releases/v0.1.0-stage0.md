고체 금속 벽을 통한 초음파 전력/데이터 전송을 위한 오픈 개러지 플랫폼의 첫 날짜가 기록된 공개 스냅샷.

## 이 태그의 의미
- 태그된 커밋 시점의 문서 + 소프트웨어 + BOM + 실험 프로토콜
- 시뮬레이터 / 목(mock) 파이프라인만 포함 — **실험실 측정 결과는 주장하지 않음**
- 인용 / 향후 Zenodo에 적합; **"벤치에서 작동한다"는 릴리스가 아님**

## 포함된 내용
- Stage-0 README 정직성 (시뮬레이터 ≠ 실험실 데이터)
- QUICKSTART + stage-1 BOM
- Sweep-map `--mock` 및 채널 시뮬레이터
- 실험 템플릿 001 / 002
- 빌드 Q&A: [Discussion #35](https://github.com/zeloras/through-metal-link/discussions/35)
- 하드웨어 바운티: [Issue #5](https://github.com/zeloras/through-metal-link/issues/5)

## 포함되지 않은 내용
- 실험 001 / 002에 대한 측정된 CSV / 사진 / 영상
- 강철을 통한 보장된 와트 수
