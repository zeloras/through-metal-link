# 하이브리드 채널: 장벽 → 물리 → 수치

> [English (primary)](../../../docs/04-hybrid-channels.md) · [Русский](../../ru/docs/04-hybrid-channels.md) · [Deutsch](../../de/docs/04-hybrid-channels.md) · [Português](../../pt/docs/04-hybrid-channels.md) · [Español](../../es/docs/04-hybrid-channels.md) · [Français](../../fr/docs/04-hybrid-channels.md) · [Italiano](../../it/docs/04-hybrid-channels.md) · [Polski](../../pl/docs/04-hybrid-channels.md) · [Türkçe](../../tr/docs/04-hybrid-channels.md) · [Українська](../../uk/docs/04-hybrid-channels.md) · [Tiếng Việt](../../vi/docs/04-hybrid-channels.md) · [中文](../../zh/docs/04-hybrid-channels.md) · [日本語](../../ja/docs/04-hybrid-channels.md) · 한국어 · [हिन्दी](../../hi/docs/04-hybrid-channels.md)

원리("투과 역설"의 따름정리): 파동은 장벽과 약하게 상호작용하는 만큼 정확히 통과한다 — 그래서 범용 채널은 존재하지 않는다. 이 플랫폼은 단일 채널을 좇지 않는다; 각 장벽마다 장벽이 투명하고 수신기가 공진적으로 "탐욕스럽게" 받아들이는 물리를 선택한다.

## 채널 선택 표

| 장벽 | 작동 채널 | 예상 (자릿수) | 비고 |
|---|---|---|---|
| 강/알루미늄 1–60 mm, 접촉 가능 | 압전-음향 (주 채널) | 와트; kbit/s (MHz 모드에서 최대 Mbit/s) | 음향 접촉 필요 (그리스 커플런트/에폭시) |
| 금속: 오염, 도장, 고온, 접촉 불희망 | EMAT (자기 → 벽 내 음향) | mW; kbit/s; 갭 최대 ~3 mm | 도전성 벽만; 전력 아닌 데이터 |
| 압전이 아예 없는 강자성 벽 | 자기왜곡 (코일이 강 자체를 구동) | 극소량; bit/s–kbit/s | 실험적 분기, 테스트 비용 저렴 |
| 진공 이중벽 (보온병, 크라이오스탯, 듀어) | 저주파 자기 (수십–수백 Hz) | µW–mW; bit/s | 표피효과: 강에서 δ≈0.6 mm @1 kHz — 주파수를 낮춰라 |
| 비금속: 유리, 플라스틱, 세라믹 | 압전-음향 (금속보다 쉬움) | 와트; kbit/s | + 순수 RF도 종종 통과함 — 먼저 확인 |
| 고무/폼 층이 있는 벽, 복합재 | 솔직히: 거의 막다름 | — | 흡수재가 전부 삼킴; 회피책은 코팅 없는 지점 |
| 벽 뒤 액체 (가득 찬 탱크) | 압전-음향, 성능 저하 | 전력 − 수 dB; 잔향 단축 | 액체 로딩이 공진을 이동/감쇠 — 가득 찬 용기 기준으로 재스윕; 캐비테이션 미만 유지 위해 연속 강도 ≲1 W/cm² 유지 ([이론](00-theory.md#벽과-그-뒤-매체에-미치는-영향)) |
| 음향 경로 상 기포 액체 | 구조적 회피 | — | 수신기를 벽에 장착, 액체를 경로 밖으로 |

## 하이브리드 노드 아키텍처

- 전력 계층: 공진 압전 쌍 (단계 1–4).
- 비접촉 데이터 계층: 분리형 "스캐너 건" 역할의 EMAT 헤드 (단계 ~6).
- 폴백 계층: 진공 샌드위치용 저주파 코일 (작업이 요구할 때).
- 발견 프로토콜(docs/03)은 "주파수 스윕"에서 "물리 스윕"으로 확장: 압전 핑 → EMAT 핑 → LF 핑; 노드가 스스로 통과하는 채널을 선택하고 자신이 보는 장벽을 보고한다.

## 채널별 응용 예시

1. **밀폐 배터리 팩 (EV/저장):** 포팅된 인클로저 내부의 T/가스 센서; 2–3 mm 알루미늄을 통과하는 압전 쌍으로 전력+데이터. 시장이 호황이고, 배터리 인클로저 투과 = 인증 지옥.
2. **크라이오스탯/듀어:** 내부 온도 로거, 진공 재킷을 통과하는 저주파 자기로 1분에 한 번 비트 패킷 전송. 음향으로는 근본적으로 불가능 — 하이브리드가 대체 불가능한 영역.
3. **압력 하의 파이프라인/오토클레이브:** 표면 전처리 제로, 뜨겁고 도장된 파이프에 밀착된 EMAT 스캐너 — 내부 수동 공진 비콘 판독.
4. **발효 탱크 (맥주/와인, 스테인리스강):** 단 하나의 관통 없이 탱크 내부 밀도/T 센서 — 위생 규정은 구멍 없음을 환영.
5. **해상 컨테이너/금고:** "화물이 살아있는가" — 골형 강판을 통과하는 압전 쌍, 휴대용 스캐너로 폴링.

## 어떤 계층도 해결 못 한계
전력 — 접촉 압전만 가능 (EMAT와 저주파 자기는 자릿수 단위로 약함). 복합/고무 라이닝 벽은 플랫폼 범위 밖. 저주파 채널 속도는 초당 비트 — 스트리밍이 아닌 원격계측.
