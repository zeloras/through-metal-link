First dated public snapshot of the open garage platform for ultrasonic power/data through solid metal walls.

## What this tag is
- Docs + software + BOM + experiment protocols as of the tagged commit
- Simulator / mock pipeline only — **no lab measurements claimed**
- Suitable for citation / later Zenodo; **not** a “it works on the bench” release

## Included
- Stage-0 README honesty (simulator ≠ lab data)
- QUICKSTART + stage-1 BOM
- Sweep-map `--mock` and channel simulator
- Experiment templates 001 / 002
- Build Q&A: [Discussion #35](https://github.com/zeloras/through-metal-link/discussions/35)
- Hardware bounty: [Issue #5](https://github.com/zeloras/through-metal-link/issues/5)

## Not included
- Measured CSV / photos / video for exp 001 / 002
- Guaranteed watts through steel
