# Гибридные каналы: барьер → физика → цифры

> [English (primary)](04-hybrid-channels.md)

Принцип (следствие «парадокса проникновения»): волна проникает через барьер ровно настолько, насколько слабо с ним взаимодействует — поэтому универсального канала не существует. Платформа не ищет один канал, а подбирает под каждый барьер ту физику, для которой барьер прозрачен, а приёмник — резонансно «жаден».

## Таблица выбора канала

| Барьер | Рабочий канал | Ожидаемо (порядки) | Примечания |
|---|---|---|---|
| Сталь/алюминий 1–60 мм, контакт возможен | Пьезо-акустика (наш основной) | ватты; кбит/с (до Мбит/с в MHz-режиме) | нужен акустический контакт (смазка/эпоксидка) |
| Металл: грязный, крашеный, горячий, контакт нежелателен | EMAT (магнитка → звук в стенке) | мВт; кбит/с; зазор до ~3 мм | только проводящие стенки; данные, не питание |
| Ферромагнитная стенка без пьезо вообще | Магнитострикция (катушка качает саму сталь) | крохи; бит/с–кбит/с | экспериментальная ветка, дёшево проверить |
| Двойная стенка с вакуумом (термос, криостат, дьюар) | НЧ-магнитка (десятки–сотни Гц) | мкВт–мВт; бит/с | скин-эффект: в стали δ≈0.6 мм @1 кГц — частоту вниз |
| Неметалл: стекло, пластик, керамика | Пьезо-акустика (легче, чем металл) | ватты; кбит/с | + обычный RF часто тоже проходит — проверять первым |
| Стенка с резиновым/пенным слоем, композит | Честно: почти тупик | — | поглотитель съедает всё; обход — точка без покрытия |
| Пузырящаяся жидкость в акустическом пути | Архитектурный обход | — | приёмник крепить к стенке, жидкость исключить из пути |

## Архитектура гибридного узла

- Силовой слой: пьезо-пара на резонансе (этапы 1–4).
- Слой данных без контакта: EMAT-головка как съёмный «сканер-пистолет» (этап ~6).
- Аварийный слой: НЧ-катушки для вакуумных сэндвичей (по запросу задачи).
- Протокол обнаружения (docs/03) расширяется с «свип по частоте» до «свип по физике»: пинг пьезо → пинг EMAT → пинг НЧ; узел сам выбирает проходящий канал и докладывает, какой барьер видит.

## Примеры применений по каналам

1. **Герметичные аккумуляторные сборки (EV/storage):** датчик T/газов внутри залитого корпуса; питание+данные пьезо-парой через алюминий 2–3 мм. Рынок растёт, врезка в корпус батареи = сертификационный ад.
2. **Криостат/дьюар:** логгер температуры внутри, раз в минуту бит-пакет НЧ-магниткой сквозь вакуумную рубашку. Акустике недоступно в принципе — здесь гибрид незаменим.
3. **Трубопровод/автоклав под давлением:** EMAT-сканер прикладывается к горячей крашеной трубе без зачистки — считывает пассивный резонансный маячок изнутри.
4. **Ферментационные танки (пиво/вино, нержавейка):** датчик плотности/T внутри танка без единой врезки — санитарные нормы любят отсутствие отверстий.
5. **Морской контейнер/сейф:** «жив ли груз» — пьезо-пара через гофросталь, опрос ручным сканером.

## Ограничения слоями не решаемые
Питание — только контактным пьезо (EMAT и НЧ-магнитка на порядки слабее). Композитные/обрезиненные стенки — вне платформы. Скорость НЧ-канала — биты/с, это телеметрия, не стриминг.
