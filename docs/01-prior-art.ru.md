# Prior art: на чём строим

> [English (primary)](01-prior-art.md)

## Правило
Каждое техническое решение в этом репо должно прослеживаться к источнику из списка «свободных» (истёкшие патенты, статьи). Живые патенты — только для чтения идей о проблемах, не для копирования claims (актуально при коммерциализации в США; см. патентную карту в проекте).

## Свободный фундамент (истёкшие/брошенные патенты = public domain)
- **US5982297** (Aerospace Corp, 1997) — базовый рецепт: пьезо-пара через стенку, питание + двусторонние данные. Главная кулинарная книга.
- US5594705 (Dynamotive, 1994) — «акустический трансформатор» через корпус.
- US6037704, US6127942 (Aerospace Corp) — питание датчиков, обратное считывание.
- **US7902943** (Caltech/JPL, умер по пошлинам 2019) — feed-through Sherrit: отражатель, акустический трансформатор.
- US9748870 (Caltech/JPL) — механическая работа через стенку.
- **US9361877** (Univ. Oklahoma, умер по пошлинам) — современная полная система трансиверов.
- US20100027379 / WO2008105947 (DOE+RPI, брошена) — несущая снаружи + нагрузочная модуляция изнутри.

## Ключевые статьи
- Lawry et al., IEEE TUFFC 2013 (10.1109/TUFFC.2013.2550) — 50 Вт + 12.4 Мбит/с, сталь 63.5 мм.
- Sherrit et al., NASA NTRS 20080048150 — 100-Вт лампа через стенку.
- Yang et al., Sensors 2015 (10.3390/s151229870) — обзор, лучшая сводка цифр.
- Ji et al., Phys. Rev. Applied 21, 014059 (2024) — метаматериал, 2%→66% через 1 мм нержавейки (патента не найдено на 07.2026).

## Чего не копируем, пока живо (US-only, до ~2032; для этапов 1–4 и не нужно)
OFDM с расстановкой поднесущих мимо гармоник силового канала (RPI US9054826); full-duplex «AM вниз + нагрузочная модуляция вверх + частотный трекинг» как единая схема (RPI US9455791); конформные трансдьюсеры для кривых поверхностей по схеме Drexel (US10594409).
