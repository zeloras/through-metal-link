# Безопасность

> [English (primary)](02-safety.md) · Русский · [Deutsch](02-safety.de.md)

1. **Высокое напряжение на пьезо.** На резонансе на выводах трансдьюсеров — сотни вольт. TVS/стабилитрон на приёмной стороне ставится ДО первого включения. Не трогать выводы при работе.
2. **Сеть.** Драйверы УЗ-ванн — с гальванической связью с сетью. Работать только через лабораторный БП / развязывающий трансформатор.
3. **Уши.** 40 кГц не слышно человеку, но субгармоники и животные — слышат. Работать с прижатыми к металлу излучателями, не с воздушными. Мощный воздушный УЗ — не включать без корпуса.
4. **Нагрев.** Ланжевен без нагрузки (не прижат) на полной мощности перегревается за минуты. Всегда проверять прижим до подачи мощности.
5. **Осколки.** Пьезокерамика хрупкая; перетянутый болт ланжевена или удар = осколки. Очки при механических работах.
